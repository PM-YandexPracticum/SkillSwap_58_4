## 5. Что работает в проекте

- React + TypeScript + Redux Toolkit по FSD.
- Начальные данные лежат в `public/db`, операции проходят через `entities/*/api`, изменения сохраняются в `localStorage`.
- Каталог поддерживает фильтры, поиск, сортировку, догрузку, лайки и избранное.
- Регистрация состоит из трёх шагов, сохраняет пользователя и навык, затем открывает каталог.
- Предложение обмена создаёт обмен, toast и уведомление; повторная попытка не создаёт дубли.
- Профиль, уведомления, пустые состояния, страницы 404/500 и защита закрытых маршрутов подключены.
- Playwright проверяет основные пользовательские сценарии в изолированном Chromium-контексте.

## 6. Как обновлять отчёт

После merge обычной задачи:

1. отметить задачу как Done в файле её фазы;
2. обновить ссылку на commit, PR и дату;
3. обновить счётчик фазы и общий счётчик;
4. сохранить исполнителя и убрать задачу из текущей очереди;
5. перепроверить зависимости и расхождения с доской.

Для P8-07 зафиксированы результаты финальной приёмки. Описание реализации не копируем сюда: для него есть файл фазы, README модулей и история изменений.
