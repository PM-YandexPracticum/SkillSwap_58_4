## 5. Как обновлять отчёт

После merge:

1. отметить задачу как Done в файле её фазы;
2. обновить ссылку на проверенный commit и дату снимка;
3. обновить счётчик фазы и общий счётчик;
4. перенести задачу в нужную колонку отчёта и сохранить исполнителя;
5. перепроверить зависимости у Todo и Backlog.

Описание реализации не копируем сюда из PR. Для него есть файл фазы, README модуля и история PR.
