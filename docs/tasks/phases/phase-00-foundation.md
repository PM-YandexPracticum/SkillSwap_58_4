# Фаза 0 — Фундамент ✅

Что я сделал до старта команды. Новые задачи здесь не появляются — это история, чтобы было понятно, откуда что взялось.
На доске вся фаза — одна карточка [#1](https://github.com/PM-YandexPracticum/SkillSwap_58_4/issues/1) «Подготовить архитектуру проекта + документация».
Библиотеки календаря и карусели в неё не входят — это отдельная задача 👑 P1-10.

### P0-01 · Разбор макета ✅ 🟡
> **Что сделано:** я прошёл все экраны Figma и решил, из каких «кирпичиков» состоит приложение:
> какие есть сущности (пользователь, навык, категория, город…), действия пользователя, крупные блоки и страницы.
> Результат — таблица «экран макета → папка в коде».

- **Результат:** [fsd.md — карта «макет → код»](../../architecture/fsd.md#5-карта-макет--код)

### P0-02 · Структура FSD и заглушки ✅ 🟡
> **Что сделано:** я разложил проект по слоям Feature-Sliced Design и создал все файлы-заглушки.
> В каждой заглушке описано (JSDoc), что в ней должно быть и к какому экрану макета она относится.
> Команде не нужно придумывать, где что лежит, — только наполнять.

- **Результат:** `src/`, README в каждой папке

### P0-03 · Store, роутер, модель данных ✅ 🟡
> **Что сделано:** я подключил Redux и все маршруты страниц и описал типы данных.
> Пользователь может научить одному навыку и хочет научиться нескольким; кого он лайкнул — хранится у него же.
> Данные — внутри приложения за слоем `entities/*/api`: образцы в JSON, изменения в localStorage.

- **Результат:** `src/app/store`, `src/app/providers/RouterProvider.tsx`, `src/entities/*/model/types.ts`

### P0-04 · Образцы данных ✅ 🟢
> **Что сделано:** для каждой сущности я подготовил 2–3 записи-образца с разными вариантами (пол, город, «О себе» есть / пусто):
> Иван, Анна и Мария, их навыки, 3 категории, 3 города, 2 обмена и 2 уведомления.
> Остальное команда заполняет по образцу (P1-05…P1-08).

- **Результат:** `src/shared/api/mock-db/seed/`

### P0-05 · Документация команды ✅ 🟢
> **Что сделано:** я записал правила работы (git, стиль кода, валидация, Storybook), архитектуру и этот план.

- **Результат:** `docs/`

### P0-06 · Каркас Storybook ✅ 🟢
> **Что сделано:** я подготовил место под Storybook: конфиги и заглушки историй у каждого компонента UI-кита.
> Пакеты Storybook установлены позднее в P1-11; в P0-06 был подготовлен только каркас.

- **Результат:** `.storybook/`, `src/shared/ui/*/*.stories.tsx`, [storybook.md](../../rules/storybook.md)

### P0-07 · Правки по онбордингу наставника ✅ 🟡
> **Что сделано:** после созвона с наставником я привёл модель и план к его требованиям.
> Лайки со счётчиком, «О себе» пустое у части пользователей, города — отдельная сущность,
> регистрация из трёх маршрутов, пагинация — догрузка по 6 при прокрутке, календарь и карусель — из библиотек.

- **Результат:** `src/entities/*/model/types.ts`, `src/shared/api/mock-db/`, `src/app/providers/RouterProvider.tsx`

### P0-08 · ТЗ и сверка с макетом ✅ 🟡
> **Что сделано:** я составил ТЗ по итогам онбординга и сверил его, транскрипцию созвона и макет между собой.
> Где источники расходятся, принял решение и записал его: фильтры — AND, поиск — Enter / лупа, шаг 2 — списки с чекбоксами,
> гость — на регистрацию с возвратом (31.10 заменено по ТЗ наставника: гость — на вход), уведомления — номинальные.

- **Результат:** [ТЗ](../../requirements/tz.md), [бэклог решений](../backlog.md)
