# Фаза 2 — UI-кит (вёрстка)

**Цель:** все базовые «кирпичики» интерфейса готовы и похожи на макет.
**После фазы:** в Storybook видны все компоненты во всех состояниях — из них собираются блоки и страницы.

Бизнес-логики здесь нет — лучшие задачи для первого PR.
**Общий критерий:** похоже на макет; все состояния (обычное, hover, focus, disabled, ошибка) есть в story; работает с клавиатуры;
только CSS-переменные; есть тест на основное поведение.
**Общая зависимость:** P1-01 (токены) и P1-11 (Storybook).

### P2-14 · FileDropzone ✅ 🟡
> **Что нужно сделать:** сделать пунктирную зону «Перетащите или выберите изображения навыка»: файл можно перетащить
> или выбрать кнопкой, выбранные фото видны превью с крестиком. В этой же задаче — утилиты проверки типа и размера файла
> (`validateImageFile`: jpg/png/webp, до 1 МБ) и превращения файла в data URL (`fileToDataUrl`) — наставник просит ограничивать файлы.
> Сам компонент файлы не проверяет: отдаёт выбранные `File[]` через `onFiles`, а ошибку и превью получает пропсами;
> проверку вызывает форма (шаг 3 — P6-05). Внутри компонента — только состояние «над зоной тащат файл».
> Для аватара этот компонент не подходит: там свой `AvatarUpload` (P3-12, P6-04), общие с ним только `validateImageFile` и `fileToDataUrl`.
> Перед сохранением `fileToDataUrl` уменьшает фото (через `canvas`, до 800 px по длинной стороне, JPEG) — иначе несколько больших фото
> займут всё место в localStorage, и «база» перестанет сохранять (P4-01 тогда бросает ошибку «Не хватает места…»).

- **Файлы:** `src/shared/ui/FileDropzone/`, `src/shared/lib/validation/validateImageFile.ts`, `src/shared/lib/image/fileToDataUrl.ts` + тесты
- **Где в макете:** «Регистрация 3 шаг» (1:1761) — рамка `Drag&Drop` (1:1770): текст и `Icon+Link` (иконка `gallery-add` + «Выбрать изображения»). У зоны одно состояние, прототипа нет.
- **Как работает (решение команды):** перетаскивание и клик мышью — по всей зоне, оба открывают выбор файла; с клавиатуры — только кнопка

  Пока над зоной тащат файл — можно выделить рамку `var(--color-accent-strong)` (в макете не нарисовано).
  Превью выбранных фото в макете не нарисованы — раскладку предлагает исполнитель на токенах (скругление `--radius-s`, крестик — `IconButton` с `cross`) и показывает скриншотом в PR.
