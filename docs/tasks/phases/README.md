## Значки

| Значок | Что значит |
|---|---|
| 🟢 🟡 🔴 | Уровень: лёгкая, средняя, сложная (подробнее — в [roadmap.md](../roadmap.md#уровни-задач)) |
| 👑 | Только тимлид (меняет `package.json` или общие настройки) |
| ✅ | Задача завершена и принята; отдельное решение о принятии P8-07 без изменений кода отражено в отчёте |
| **Уже готово:** | Часть задачи уже сделана заранее — это **не** делаем заново, только дописываем остальное |

## Формат задачи

Совпадает с шаблоном issue на GitHub — переносится на доску копированием.

```
### P2-02 · Кнопки Button и IconButton 🟢    ← ID · название · уровень (👑 — тимлид или помощник)
> **Что нужно сделать:** 3–4 предложения:    ← «Что нужно сделать» в issue
> начинается с действия, дальше — где на макете и на что обратить внимание.

- **Уже готово:** ...                         ← только если часть уже сделана: не дублируем
- **Файлы:** ...                              ← где работать
- **Где в макете:** ...                       ← «Скрины / макет» в issue
- **Зависит от:** ...                         ← «Связанные задачи» в issue
- **Issue:** [#N](...)                         ← появляется, когда карточка создана на доске
- **Готово, когда:** ...                      ← «Acceptance criteria» (+ общий критерий фазы)
```

В начале каждого файла фазы после цели находится блок **«Архитектурная роль фазы»**. Он отвечает на пять одинаковых вопросов: за что отвечает фаза, что подключает, что использует, чего не дублирует и какой результат передаёт дальше. Статусы и конкретные файлы остаются в описаниях задач ниже.

Задача сделана — ставим ✅ после названия: `### P2-02 · Кнопки Button и IconButton ✅ 🟢`.

Для полностью закрытой фазы дата статуса не указывается: у её задач достаточно постоянной отметки `Статус: Done`. Дату текущего снимка сохраняем только в открытых фазах и сводных отчётах, где она помогает сверять In Progress, Review, Todo и Backlog.
