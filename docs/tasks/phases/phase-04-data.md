# Фаза 4 — Данные и вход (логика)

**Цель:** данные из «базы» внутри приложения загружаются в Redux при старте, изменения сохраняются, можно войти.
**После фазы:** любой компонент берёт данные из store; «база» — за слоем `entities/*/api`, её можно заменить на настоящую.
P4-01 делаем первой — остальные задачи фазы читают и пишут через неё.

### P4-01 · «База данных» в браузере ✅ 🔴
> **Что нужно сделать:** реализовать «базу» внутри приложения: образцы — JSON в `shared/api/mock-db/seed/`, изменения
> (регистрация, лайки, профиль, обмены) сохраняются поверх них в localStorage. Основа — функция `createMockCollection`:
> «коллекция» с методами получить все / по id / создать / изменить / удалить, с имитацией задержки сервера и без мутаций.
> Потом JSON переедут в `public/db` (P4-10), а позже можно подключить и настоящую БД — поменяются только файлы `entities/*/api`.

- **Уже готово:** слой `entities/*/api` для всех 6 сущностей и подключение образцов (`SEED`) — остаётся только сама `createMockCollection` и `resetMockDb`.
- **Файлы:** `src/shared/api/mock-db/createMockCollection.ts` + тесты

### P4-03 · Пользователи и навыки 🟡
> **Что нужно сделать:** загрузить пользователей и навыки из «базы» и сделать селекторы: по id, по email, навык автора,
