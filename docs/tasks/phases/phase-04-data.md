# Фаза 4 — Данные и вход (логика)

**Цель:** данные из «базы» внутри приложения загружаются в Redux при старте, изменения сохраняются, можно войти.
**После фазы:** любой компонент берёт данные из store; «база» — за слоем `entities/*/api`, её можно заменить на настоящую.
P4-01 делаем первой — остальные задачи фазы читают и пишут через неё.
