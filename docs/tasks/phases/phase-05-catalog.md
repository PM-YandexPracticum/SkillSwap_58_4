# Фаза 5 — Каталог и избранное (логика)

**Цель:** главная страница работает целиком.
**После фазы:** секции сортируются и раскрываются, работают фильтры, поиск, лента с догрузкой, лайки, избранное, шапка вошедшего.
Вёрстка уже готова (фаза 3) — здесь её «оживляем».

### P5-01 · Логика фильтров 🔴
> **Что нужно сделать:** сделать состояние фильтров в store (режим, подкатегории, пол, города, сортировка) и чистую функцию
> `applyFilters`, которая оставляет подходящих пользователей с учётом строки поиска и сортирует по дате.
> По ТЗ фильтры комбинируются логикой **AND**: пользователь должен подходить под поиск И режим И навыки И пол И город;
> внутри одного блока несколько отмеченных значений — «любой из». Это ядро каталога — каждый фильтр и их сочетания покрываем тестами.

- **Уже готово:** типы фильтров и селектор `selectActiveFiltersCount`.
- **Файлы:** `src/features/catalog-filter/model/`, `src/features/catalog-filter/lib/applyFilters.ts` + тесты
- **Зависит от:** P4-03

### P5-02 · Панель фильтров в действии 🟡

> Каталог перестраивается сам, как только меняются фильтры в store.

- **Файлы:** `src/widgets/filters-panel/`, `src/features/catalog-filter/ui/` (те же, что в P3-07)
