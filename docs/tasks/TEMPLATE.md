# Шаблон задачи

Повторяет шаблон issue на GitHub (`.github/ISSUE_TEMPLATE/feature.md`) — при создании карточки просто заполни поля.
Для задач из плана всё уже написано в файле фазы: копируй блок целиком.

```markdown
Название: [P2-02] Кнопки Button и IconButton

## Что нужно сделать
3–4 простых предложения: начинаем с действия («сделать…», «подключить…»), дальше — где на макете и на что обратить внимание.

Уже готово: (если часть сделана заранее — перечислить, чтобы не делать дважды)

## Скрины / макет
Скриншот нужного места из Figma + ссылка на фрейм (node id).

## Acceptance criteria
- [ ] Совпадает с макетом (визуальное сходство, не pixel perfect)
- [ ] Импорты по правилам FSD (только вниз, через `index.ts`)
- [ ] Есть story со всеми состояниями (для компонентов UI)
- [ ] `npm run lint`, `npx tsc --noEmit`, `npm run test`, `npm run build` — зелёные
- [ ] В коммите только мои файлы

## Связанные задачи
Ссылки на issues, которые должны быть сделаны раньше («Зависит от» в плане).
```
