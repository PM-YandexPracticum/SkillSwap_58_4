# Документация SkillSwap

SkillSwap — десктопная платформа обмена навыками. Пользователь показывает, чему может научить, находит подходящее предложение и предлагает обмен.

Проект — фронтенд на React, TypeScript и Redux Toolkit. Начальные данные лежат в JSON-моках, операции идут через API-слой сущностей, изменения сохраняются в localStorage.
