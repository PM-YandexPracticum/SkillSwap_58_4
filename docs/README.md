# docs — документация команды SkillSwap

> **SkillSwap** — платформа обмена навыками: пользователь показывает, чему может научить, находит тех,
> у кого хочет научиться, и предлагает обмен. Проект — только фронтенд (React + TypeScript + Redux Toolkit),
> данные хранятся в JSON-моках и localStorage.

Здесь лежит всё, что не является кодом, но нужно для разработки: правила, архитектура, задачи.
Если ты новичок в команде — читай сверху вниз.

**Состояние на 13.11.2026:** завершены 69 из 86 задач MVP (с фундаментом — 78). UI-кит — 18/18, вёрстка — 16/16, данные — 9/10, каталог — 5/9, регистрация — 2/6, навык/обмен — 4/6, финиш — 1/7. Последняя закрытая задача — шаг 3 регистрации и окна (P3-13, PR #196; исходная история сохранена обычным merge в PR #197). Фазы 0–3 полностью завершены. Ранее приняты результаты и сортировка каталога (P5-05), черновик регистрации и охрана шагов (P6-01), создание обмена (P7-03). В P8-02 приняты четыре личных вклада; общая карточка открыта в Review. Назначения и проверки — в [отчёте](tasks/report.md), свободные задачи и компоненты — в [справке](tasks/guide-phase-2-3.md).
