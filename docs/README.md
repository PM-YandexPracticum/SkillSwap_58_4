# docs — документация команды SkillSwap

> **SkillSwap** — платформа обмена навыками: пользователь показывает, чему может научить, находит тех,
> у кого хочет научиться, и предлагает обмен. Проект — только фронтенд (React + TypeScript + Redux Toolkit),
> данные хранятся в JSON-моках и localStorage.

Здесь лежит всё, что не является кодом, но нужно для разработки: правила, архитектура, задачи.
Если ты новичок в команде — читай сверху вниз.

**Состояние на 12.11.2026:** завершены 63 из 86 задач MVP (с фундаментом — 72). UI-кит — 18/18, вёрстка — 15/16, данные — 8/10, каталог — 4/9, навык/обмен — 3/6, финиш — 1/7. Последние влитые задачи: общая загрузка DataProvider, вёрстка кабинета, секции «Популярное» / «Новое» и корневой ErrorBoundary. В P8-02 приняты четыре личных вклада; общая карточка открыта в Review. Бизнес-вход и остальные сценарии выполняются по плану. Назначения и проверки — в [отчёте](tasks/report.md), свободные задачи и компоненты — в [справке](tasks/guide-phase-2-3.md).
