## Главные правила

1. **Проверяем всё, что вводит пользователь**: поля форм, файлы, параметры URL (`/skill/:id`, `?page=`).
2. **В форме** (yup + react-hook-form). Правила, которые требуют данных (email не занят), проверяются ещё и в `entities/*/api` перед сохранением.
3. **Одни правила на весь проект**: формы собирают схемы из полей `@/shared/lib/validation`, а не пишут свои.
4. **Перед проверкой обрезаем пробелы** по краям (`trim`); строка из одних пробелов — пустая.
5. **Ошибка — под полем, по-русски и по делу**: что не так и как исправить. Показываем после ухода с поля или по «Отправить».
6. **Кнопка отправки неактивна**, пока форма невалидна или идёт сохранение.
7. **При входе ошибка одна общая** — «Email или пароль введён неверно», не подсказываем, что именно.

## Поля

| Поле | Правило | Текст ошибки |
|---|---|---|
| Email | обязателен, формат `имя@домен.зона`, до 254 символов, хранится в нижнем регистре | «Введите email» / «Введите корректный email» |
| Email при регистрации | + не занят среди пользователей (без учёта регистра) | «Email уже используется» (ТЗ наставника) |
| Пароль | 8–64 символа, хотя бы одна буква и одна цифра, без пробелов | «Пароль должен содержать не менее 8 знаков» / «…хотя бы одну букву и одну цифру» |
| Повтор пароля | совпадает с паролем | «Пароли не совпадают» |
| Имя | обязательно, 2–40 символов, буквы (кириллица/латиница), пробел, дефис | «Введите имя» / «Только буквы, пробел и дефис» |
| Дата рождения | обязательна, корректная дата, не в будущем, возраст 14–100 лет | «Укажите дату рождения» / «Возраст от 14 до 100 лет» |
| Пол | «Не указан», мужской или женский — по макету можно не указывать | — |
| Город | только id из справочника городов | «Выберите город из списка» |
| О себе | только в профиле (при регистрации пустое), необязательно, до 500 символов | «Не больше 500 символов» |
| Хочу научиться | 1–10 уникальных подкатегорий из справочника, отмеченных в списке с чекбоксами; подкатегория принадлежит отмеченной категории | «Выберите хотя бы одно направление» / «Не больше 10 направлений» / «Выберите направления из списка без повторов» |
| Может научить | ровно один навык | — (поле одно) |
| Название навыка | обязательно, 3–50 символов | «От 3 до 50 символов» |
| Категория / подкатегория | обязательны, подкатегория принадлежит категории (выбор подкатегории сам подставляет категорию) | «Выберите категорию» |
| Описание навыка | обязательно, 20–500 символов (максимум — из исходного ТЗ) | «Расскажите подробнее — от 20 символов» / «Не больше 500 символов» |
| Фото навыка | 1–4 файла | «Добавьте от 1 до 4 фото» |
| Любая картинка (аватар, фото навыка) | файл jpg, png или webp, до 1 МБ; перед сохранением уменьшается до 800 px и хранится как data URL в localStorage | «Только JPG, PNG или WEBP» / «Файл больше 1 МБ» |
| Поиск | до 100 символов, без проверки формата | — |

## Тесты

У каждого правила — unit-тест: подходящее значение, граница (ровно 8 символов), значение за границей, пустое значение.
