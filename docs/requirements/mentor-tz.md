## Проект «SkillSwap» — платформа обмена навыками

### 1. Название и краткое описание

SkillSwap — одностраничное приложение (SPA), в котором пользователи обмениваются навыками. У каждого пользователя есть:

- «Может научить» — навык, который он предлагает (название, категория / подкатегория, описание, изображения);
- «Хочет научиться» — подкатегории, которые ему интересны.

В каталоге выводятся карточки пользователей с их предложениями. Пользователь находит подходящее предложение через поиск и фильтры, добавляет его в избранное или предлагает обмен.

Бэкенда в проекте нет, все данные моковые:

- пользователи, навыки, категории и города — JSON-файлы в `public/db`;
- текущий пользователь (mock-токен), зарегистрированные пользователи, избранное, уведомления — `localStorage`.

Обмен в проекте не происходит по-настоящему: при нажатии «Предложить обмен» приложение отправляет уведомление самому пользователю — «Вы предложили обмен Ивану».

### 2. Пользовательский сценарий (User Flow)

| № | Действие | Результат / условие завершения |
|---|---|---|
| 1 | Гость открывает главную страницу | Отображается каталог карточек, в шапке кнопки «Войти» и «Зарегистрироваться» |
| 2 | Прокручивает ленту | Через 1 секунду подгружаются следующие 6 карточек |
| 3 | Ищет навык или применяет фильтры | Список обновляется без перезагрузки, выводится «Подходящие предложения: N» |
| 4 | Нажимает «Предложить обмен» | Если не авторизован — редирект на вход, после входа возврат на предыдущую страницу |
| 5 | Проходит регистрацию из 3 шагов | Шаг 1 — email и пароль; шаг 2 — данные о себе и что хочет изучить; шаг 3 — свой навык. Перед сохранением — модалка «Ваше предложение» с кнопками «Редактировать» и «Готово» |
| 6 | Нажимает «Готово» | Пользователь авторизован, попадает в каталог, его карточка появляется в ленте |
| 7 | Предлагает обмен | Кнопка меняется на «Обмен предложен», появляются toast и уведомление в колокольчике «Вы предложили обмен …» |
| 8 | Добавляет карточку в избранное | Сердечко закрашивается, карточка появляется на странице избранного |
| 9 | Открывает профиль | Видит и редактирует личные данные |

### 3. Обязательные задачи (MVP)

#### 3.1. Каталог и пагинация

- Загрузка карточек из мока.
- Карточка: аватар, имя, город, возраст, «Может научить», «Хочет научиться» (до 2 тегов + «+N»), сердечко, кнопка.
- При прокрутке ленты — debounce 1 секунда, затем догружается 6 карточек.

**Готово, когда:** главная рендерит карточки из мока, при прокрутке подгружаются новые порциями по 6.

#### 3.2. Поиск и фильтры

- Поиск в шапке по названию навыка.
- Radio «Всё / Хочу научиться / Могу научить».
- «Навыки»: категории с раскрывающимися подкатегориями.
- «Пол автора», «Город».
- Счётчик «Фильтры (N)», кнопка «Сбросить», чипсы активных фильтров над списком.

**Готово, когда:** фильтры комбинируются между собой, сброс возвращает исходную ленту.

#### 3.3. Аутентификация

- Вход: email и пароль; при неверных данных — «Email или пароль введён неверно».
- Регистрация, шаг 1: email, пароль (не менее 8 символов), ошибка «Email уже используется».
- Шаг 2: имя, дата рождения, пол, город, категория и подкатегория навыка, которому хочет научиться.
- Шаг 3: название навыка, категория, подкатегория, описание, изображения → модалка «Ваше предложение».
- Данные хранятся в `localStorage`, токен — произвольная строка.

**Готово, когда:** после входа происходит редирект на предыдущий URL; после регистрации карточка пользователя появляется в каталоге.

#### 3.4. Заявки на обмен

- Кнопка «Предложить обмен» → «Обмен предложен».
- Toast и уведомление себе: «Вы предложили обмен …».
- Колокольчик в шапке: список уведомлений, «Прочитать все», «Очистить».

**Готово, когда:** после предложения обмена кнопка меняет состояние, уведомление сохраняется после перезагрузки.

#### 3.5. Профиль пользователя

- Рабочая вкладка одна — «Личные данные»: почта, имя, дата рождения, пол, город, о себе, аватар, кнопка «Сохранить».
- Остальные пункты меню («Заявки», «Мои обмены», «Избранное», «Мои навыки») — заглушки.

**Готово, когда:** изменения сохраняются и отображаются в шапке; гость при переходе в профиль попадает на вход.

#### 3.6. Избранное

- Сердечко на карточке.
- Страница избранного (иконка в шапке).

**Готово, когда:** избранное сохраняется после перезагрузки; при пустом списке — кнопка «Вернуться в каталог».

#### 3.7. Роутинг и 404

- React Router ≥ v6, lazy-загрузка страниц.

**Готово, когда:** несуществующий URL ведёт на страницу 404 с кнопкой «На главную».

### 4. Дополнительные задачи

| Приоритет | Функция | Краткие критерии приёмки |
|---|---|---|
| Высокий | Бэкенд (по желанию команды) | Свой сервер вместо моков: пользователи, авторизация, избранное, заявки. Фронт работает с API без изменения интерфейса |
| Высокий | Тёмная тема | Переключатель в шапке, CSS-переменные, выбор сохраняется |
| Средний | Бейджи / достижения | Набор бейджей, при выдаче появляется toast |
| Низкий | Внутренний чат-заглушка | WebSocket-мок, история хранится в `localStorage` |
| Низкий | PWA-офлайн | Service Worker, offline-fallback страница |
