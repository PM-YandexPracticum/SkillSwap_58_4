# Мои незакрытые технические заметки

Я оставил здесь только вопросы, которые ещё не закрыты в проекте. Это мои рабочие заметки,
а не новые задачи и не изменение статусов на доске.

## 1. Защита шагов регистрации — P6-01

`RegisterStepGuard` пока не использует номер шага для проверки доступа. При прямом открытии URL
пользователь может попасть на следующий шаг без заполнения предыдущих данных.

Что нужно сделать владельцу P6-01:

- хранить завершённые шаги и черновик в одном состоянии;
- перенаправлять пользователя на первый незавершённый шаг;
- определить поведение после обновления страницы;
- проверить прямое открытие шагов 2 и 3;
- проверить переход назад, переход вперёд и открытие уже завершённого шага.

Подключение форм регистрации остаётся в задачах P6-02, P6-04 и P6-05.

## 2. Сквозные пользовательские сценарии — P8-05

В проекте есть конфигурация Playwright и команда запуска, но стабильных пользовательских сценариев
пока нет. Флаг `--pass-with-no-tests` оставлен временно, чтобы заготовка не блокировала разработку.

В P8-05 нужно добавить сценарии критических путей и убрать этот флаг после появления первого
стабильного набора E2E-тестов.
