# src/pages/catalog/lib

Архитектура — [Feature-Sliced Design](../../../../docs/architecture/fsd.md).

Чистые функции композиции каталога. Соседние features не импортируют друг друга: данные и действия соединяет страница.

- `buildActiveFilters.ts` — строит плашки режима, подкатегорий, пола и городов из состояния фильтров и справочников. Неизвестные id без подписи пропускает. Поиск остаётся отдельным полем Header.
- `parseFilterRemoval.ts` — переводит id плашки (`mode`, `gender`, `sort`, `skill:…`, `city:…`) в `FilterRemoval` для действия `removeFilter`. Неизвестный формат вызывает ошибку, поэтому вызывающий код передаёт только поддержанные id.
- `*.test.ts` — порядок и подписи плашек, пустые/неизвестные данные, разбор поддержанных id и отказ для неизвестного формата.

Фильтрацию и сортировку выполняет общая `applyFilters` из `@/features/catalog-filter`; здесь второго алгоритма нет.
