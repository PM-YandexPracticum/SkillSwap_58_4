# src/pages/catalog

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Главная страница — каталог предложений (`/`). Вёрстка P3-10 собрана на готовых виджетах; подключение лайков и догрузки остаётся задачам фазы 5; фильтры, поиск и результаты уже подключены. Состояния страницы проверяются в Storybook.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- [`lib/`](lib/README.md) — подписи плашек и перевод удаления в действие фильтра
- `index.ts` — публичный API — импортировать снаружи только отсюда
