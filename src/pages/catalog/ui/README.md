# src/pages/catalog/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `catalog` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `CatalogPage.tsx` — Главная / каталог. FiltersPanel слева; справа: - без фильтров и поиска — «Популярное» (по likesCount) и «Новое» (по createdAt) по 3 карточки с «Смотреть все» (до 9), «Рекомендуем» — все пользователи в случайном порядке, лента с догрузкой по 6; - с фильтрами или поиском — «Подходящие предложения: N»: плашки фильтров (ActiveFilters), SortToggle, лента с догрузкой. Всегда 3 колонки — только десктоп
