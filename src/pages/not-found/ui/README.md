# src/pages/not-found/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `not-found` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** страница пока выводит заголовок и «Страница в разработке». Иллюстрация готова; вёрстка — P3-16, маршрут `*` уже объявлен. Описания ниже задают целевую ответственность файлов.

## Что внутри

- `NotFoundPage.tsx` — Ошибка 404: заголовок, описание, картинка, «Сообщить об ошибке» (заглушка, ничего не делает) и «На главную». Переход на любой неизвестный адрес и несуществующий навык ведёт сюда.
- `NotFoundPage.module.css` — стили страницы. Figma (1:2048)
- `NotFoundPage.stories.tsx` — Storybook: `Default` с `MemoryRouter` и `ROUTER_FUTURE`, ссылка на макет «404» (1:2048)
- `NotFoundPage.test.tsx` — Vitest: контракт с макетом (заголовок, описание, картинка, две кнопки), `it.each` по неизвестным адресам → 404, переход по «На главную», заглушка «Сообщить об ошибке»
