# Личный кабинет

`/profile/*` доступен вошедшему пользователю через RequireAuth. `ProfilePage` соединяет боковую навигацию и вложенный раздел.

«Личные данные» — рабочий редактор профиля: сохраняет почту, имя, дату рождения, пол, город, «О себе», фото и при необходимости новый пароль. Данные обновляются в общем store и доступны шапке и странице навыка. После перезагрузки они читаются из учебной базы.

«Заявки», «Мои обмены», «Избранное» и «Мои навыки» внутри кабинета остаются заглушками по условиям проекта. Рабочая страница избранного находится отдельно, по `/favorites`.

[ui/](ui/README.md) содержит компоновку и разделы. `index.ts` — публичный API страницы. Архитектура — [FSD](../../../docs/architecture/fsd.md).
