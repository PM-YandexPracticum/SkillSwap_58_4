# src/pages/profile/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `profile` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** вёрстка кабинета готова в P3-14 (PR #183). ProfilePage соединяет ProfileSidebar и Outlet; ProfilePersonal выводит ProfileForm и Avatar пользователя из store. Остальные разделы используют ProfileStub. Сохранение личных данных, смена пароля и выбор аватара — P7-06. RequireAuth на `/profile/*` уже готов.

## Что внутри

- `ProfileExchanges.tsx` — Раздел «Мои обмены» — по решению команды остаётся МОКОМ: заголовок + текст «Раздел в разработке». Рабочий раздел кабинета только один — «Личные данные»
- `ProfileFavorites.tsx` — Раздел «Избранное» — по решению команды остаётся МОКОМ: заголовок + текст «Раздел в разработке». Рабочий раздел кабинета только один — «Личные данные»
- `ProfilePage.tsx` — Личный кабинет `/profile/*`: ProfileSidebar слева, справа — вложенный раздел через <Outlet />
- `ProfilePersonal.tsx` — Вёрстка «Личных данных»: ProfileForm + Avatar и кнопка «Изменить аватар». Без пользователя из store возвращает null; сохранение и обработка аватара — P7-06
- `ProfileRequests.tsx` — Раздел «Заявки» — по решению команды остаётся МОКОМ: заголовок + текст «Раздел в разработке». Рабочий раздел кабинета только один — «Личные данные»

- `ProfilePage.stories.tsx`, `ProfilePersonal.stories.tsx`, `ProfilePersonal.test.tsx` — демонстрации и проверки вёрстки кабинета
