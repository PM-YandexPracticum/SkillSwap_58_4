# src/pages/about

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Страница «О проекте» (`/about`) — команда проекта: фото, роли, GitHub.

**Текущее состояние:** страница готова (P3-16): заголовок и сетка карточек из `config/team.ts`. Список участников заполняется постепенно — каждый добавляет себя сам в P8-02, поэтому карточек становится больше со временем.

## Что внутри

- [`config/`](config/README.md) — Данные страницы «О проекте»: список участников команды (`team.ts`)
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
