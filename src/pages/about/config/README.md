# src/pages/about/config

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Данные страницы «О проекте»: список участников команды (`team.ts`), заполненный в рамках P8-02.

## Что внутри

- `team.ts` — тип `TeamMember` и массив `TEAM`. В массиве есть карточки всех 11 участников проекта. Для участников без фотографии используется `photoUrl: null`: страница показывает общий fallback-аватар.

У Кирилла, Андрея, Дианы и Ирины указаны фотографии и авторские тексты. Для остальных карточек пока используется текст `Описание дополняется.` и общий fallback-аватар.

ID участника — постоянный логин GitHub. `nanoid` для статической конфигурации и fixtures не используется.
