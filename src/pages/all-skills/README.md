# src/pages/all-skills

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Страница «Все навыки» (`/skills`) — ссылка из футера. Статичный список категорий и подкатегорий.

**Текущее состояние:** страница пока выводит заголовок и «Страница в разработке». Меню и список категорий — P3-06. Описания ниже задают целевую ответственность файлов.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
