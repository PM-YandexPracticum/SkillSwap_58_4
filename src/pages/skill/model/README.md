# src/pages/skill/model

Модель страницы навыка: композиция данных нескольких сущностей через их публичные API.

- `selectSimilarUsers.ts` — мемоизированный подбор других авторов, чей предлагаемый навык относится к подкатегории текущего. Получает публичных пользователей через `selectUsers`, навыки — через `selectSkills`. Порядок сохраняется, отсутствующие навыки и ссылки на чужое предложение пропускаются. Без совпадений возвращается пустой список. Запросов и сохранения здесь нет.
- `selectSimilarUsers.test.ts` — подбор по подкатегории, исключение автора, отсутствие паролей, порядок и неизменность данных, мемоизация, смена навыка и обновление коллекций.

Эта композиция принадлежит странице, потому что соединяет user и skill. Сущность user не читает состояние соседнего слайса. Количество видимых карточек и прокрутку определяет карусель, а не селектор.
