# src/pages/skill/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** SkillPage подключена к Redux-состоянию: отображает данные навыка и автора, обрабатывает переходные loading/error/404-состояния и передаёт готовые пропсы виджетам. Стартовую загрузку общих данных выполняет `DataProvider` в роутере.

Похожие предложения выбирает `selectSimilarUsers(state, skillId)` из `@/entities/user`.
При переходе по «Подробнее» меняются навык и список похожих, прокрутка возвращается к началу страницы,
а фокус — на основной контент с названием нового навыка. Галерея и карусель начинают показ с первого слайда.
Обновление данных текущего навыка не сбрасывает прокрутку и фокус.
Если совпадений нет, заголовок и карусель скрыты. Карточки — тот же `OfferCard`, что и в каталоге;
лайки и реальный обмен остаются в P5-07 и P7-03.

## Что внутри

- `SkillPage.tsx` — Страница навыка `/skill/:id`: SkillDetails + OffersCarousel + окно «Вы предложили обмен»; данные и справочники из Redux-селекторов после общей загрузки DataProvider; собственных стартовых запросов у страницы нет
- `SkillPage.stories.tsx`, `SkillPage.test.tsx` — stories и тесты
