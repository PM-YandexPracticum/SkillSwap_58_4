# src/pages/register

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Регистрация — три маршрута `/register/step-1…3` с общей рамкой (Stepper + иллюстрация).

**Текущее состояние:** в P3-11 и P3-12 готовы общая рамка со Stepper, иллюстрации и вёрстка шагов 1–2. P6-01 добавляет черновик в памяти, охрану шагов 2–3 и сброс при выходе из регистрации через RegisterDraftLifecycle. Подключение форм к черновику и отметке пройденных шагов — P6-02/04/05; пока «Далее» на настоящей форме первого шага не отмечает шаг пройденным, поэтому guard возвращает на шаг 1. Шаг 3 остаётся задачей P3-13; завершение — P6-06.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
