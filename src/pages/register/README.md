# src/pages/register

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Регистрация — три маршрута `/register/step-1…3` с общей рамкой (Stepper + иллюстрация).

**Текущее состояние:** в P3-11, P3-12 и P3-13 готовы общая рамка со Stepper, иллюстрации и вёрстка шагов 1–3; на шаге 3 есть превью «Ваше предложение». P6-01 добавляет черновик в памяти, охрану шагов 2–3 и сброс при выходе из регистрации через RegisterDraftLifecycle. В P6-02 подключён первый шаг: значения восстанавливаются из черновика, проверяются формат и уникальность email, при успешной проверке данные сохраняются, шаг отмечается пройденным и открывается шаг 2. В P6-04 подключён второй шаг: проверенные поля сохраняются перед переходом на шаг 3, при возврате назад сохраняются текущие значения без проверки; аватар записывается в черновик готовым data URL. На шаге 3 подключены валидация навыка, фото, превью и запись по «Готово» (P6-05/P6-06). При ошибке введённое сохраняется, повтор использует прежние IDs и обновляет частично записанную пару. Формы и окна можно проверить отдельно в Storybook.
