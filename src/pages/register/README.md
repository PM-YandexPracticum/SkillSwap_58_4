# src/pages/register

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Регистрация — три маршрута `/register/step-1…3` с общей рамкой (Stepper + иллюстрация).

**Текущее состояние:** в P3-11, P3-12 и P3-13 готовы общая рамка со Stepper, иллюстрации и вёрстка шагов 1–3, на шаге 3 есть превью «Ваше предложение». «Далее» и «Продолжить» переводят между шагами без сохранения данных. Guard и черновик — P6-01, валидация шага 1 — P6-02, завершение — P6-06.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- [`lib/`](lib/README.md) — чистая сборка данных превью навыка
- `index.ts` — публичный API — импортировать снаружи только отсюда
