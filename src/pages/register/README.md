# src/pages/register

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Регистрация — три маршрута `/register/step-1…3` с общей рамкой (Stepper + иллюстрация).

**Текущее состояние:** в P3-11, P3-12 и P3-13 готовы общая рамка со Stepper, иллюстрации и вёрстка шагов 1–3; на шаге 3 есть превью «Ваше предложение». P6-01 добавляет черновик в памяти, охрану шагов 2–3 и сброс при выходе из регистрации через RegisterDraftLifecycle. В P6-02 подключён первый шаг: значения восстанавливаются из черновика, проверяются формат и уникальность email, при успешной проверке данные сохраняются, шаг отмечается пройденным и открывается шаг 2. Подключение форм шагов 2–3 относится к P6-04/P6-05. Формы и окна можно проверить отдельно в Storybook. Сохранение и завершение регистрации — P6-06.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- [`lib/`](lib/README.md) — чистая сборка данных превью навыка
- `index.ts` — публичный API — импортировать снаружи только отсюда
