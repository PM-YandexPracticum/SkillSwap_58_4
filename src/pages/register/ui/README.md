# src/pages/register/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `register` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** готовы RegisterLayout и RegisterStep1Page (P3-11). Номер Stepper и иллюстрация определяются маршрутом. Форма шага 2 готова (P3-12), шаг 3 с превью готов (P3-13); защита шагов и черновик готовы в P6-01, сохранение данных шагов и переходы — P6-02…P6-06.

## Что внутри

- `RegisterLayout.tsx` — Общая часть трёх шагов регистрации: Stepper «Шаг N из 3» сверху, форма шага слева (Outlet), справа иллюстрация и подпись текущего шага. Логотип и «Закрыть ×» — из AuthLayout. Черновик и прогресс принадлежат features/register. При выходе из маршрутов регистрации их очищает RegisterDraftLifecycle в app/router; лейаут не сбрасывает данные в cleanup.
- `RegisterStep1Page.tsx` — Шаг 1: email и пароль — маршрут `/register/step-1`. OAuthButtons и StepCredentials подключены через публичные API; после проверки «Далее» сохраняет данные в черновик и открывает шаг 2
- `RegisterStep2Page.tsx` — Шаг 2 «Расскажите немного о себе» — маршрут `/register/step-2`. Собирает `StepProfile` и `AvatarUpload` через публичные API. «Назад» сохраняет текущие поля, «Продолжить» — проверенные и прогресс шага 2. Фото сразу попадает в черновик готовым data URL; до окончания чтения продолжение заблокировано. После ухода позднее фото не применяется. Загрузка и ошибки справочников остаются в `DataProvider`
- `RegisterStep3Page.tsx` — Шаг 3 «Укажите, чем вы готовы поделиться» — маршрут `/register/step-3`. Собирает `StepSkill` с `SkillForm` и `SkillPreviewModal`, категории читает из store (их загружает DataProvider). «Назад» — шаг 2, «Продолжить» — превью, «Редактировать» — возврат к форме с введёнными данными, «Готово» — каталог с `state.offerCreated`. Ничего не сохраняет

- `RegisterLayout.test.tsx` — маршруты всех шагов, редирект /register и переход «Далее»
- `RegisterLayout.module.css` — вертикальные отступы второго шага по Figma.
- `RegisterStep2Page.test.tsx` — сохранение полей и прогресса, возврат и восстановление черновика, проверка и чтение аватара, ожидание фото и уход до завершения чтения.
- `RegisterLayout.stories.tsx` — рамка каждого шага и настоящие формы шагов 1–3. Локальный store содержит register, users и справочники; провайдеры приложения в Storybook не требуются.
- `RegisterStep3Page.test.tsx` — переходы, превью с данными и фото, возврат к форме, Loader и ошибка категорий.
