# src/pages/favorites

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Избранное (`/favorites`, только для вошедших): люди из `likedUserIds` текущего пользователя.

**Текущее состояние:** P5-08 реализует страницу для вошедшего пользователя: список строится из его `likedUserIds`, поддерживает поиск, фильтры и догрузку карточек. При пустом списке или отсутствии совпадений показывается понятное состояние с действием для восстановления. `RequireAuth` подключён маршрутизатором.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
