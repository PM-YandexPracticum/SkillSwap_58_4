# src/pages/favorites

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Избранное (`/favorites`, только для вошедших): люди из `likedUserIds` текущего пользователя.

**Текущее состояние:** страница пока выводит заголовок и «Страница в разработке». Данные, фильтры и лента избранного — P5-08; RequireAuth уже подключён. Описания ниже задают целевую ответственность файлов.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
