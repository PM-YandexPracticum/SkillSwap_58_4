# src/pages/favorites/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `favorites` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** P5-08 реализована. Страница отображает избранных пользователей текущего авторизованного пользователя, поддерживает поиск и фильтрацию по избранным, а также бесконечную прокрутку с догрузкой по 6 карточек. При снятии лайка карточка сразу исчезает из списка. Доступ к странице ограничен через `RequireAuth`.

## Что внутри

- `FavoritesPage.tsx` — страница «Избранное» (`/favorites`): получение избранных пользователей через `selectFavoriteIds`, применение поиска и фильтров, отображение карточек через `OfferCard` и `OffersSection`, бесконечная прокрутка через `useInfiniteScroll`.
- `FavoritesPage.test.tsx` — тесты страницы: отбор избранных пользователей, авторизация, пустые состояния, сброс фильтров, обновление данных в store и бесконечная прокрутка.

При прямом входе страница вызывает общий `loadExchangesIfNeeded`, чтобы `OfferCard` показывал сохранённое состояние «Обмен предложен». Повторные запросы отсеивает сам thunk. Общий сброс вызывает публичные действия `resetFilters` и `queryCleared`.

Отсутствие избранного и отсутствие совпадений различаются: в первом случае можно вернуться в каталог, во втором — сбросить поиск и фильтры. Пока общий `EmptyState` не реализован в P8-03, это локальное представление страницы; загрузкой и ошибками начальных данных управляет `DataProvider`.
