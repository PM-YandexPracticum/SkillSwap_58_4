# src/pages/server-error/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `server-error` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** страница готова (P3-16): заголовок, описание, картинка и две кнопки («Сообщить об ошибке» — заглушка по ТЗ, «На главную» → `/`).

## Что внутри

- `ServerErrorPage.tsx` — Ошибка 500: заголовок, описание, картинка, «Сообщить об ошибке» (заглушка, ничего не делает) и «На главную». Использует shared/ui/ErrorPage, открывается по `/500`; показ из `ErrorBoundary` при падении рендера подключит P8-01
- Стили рамки и действий предоставляет `shared/ui/ErrorPage`. Figma (1:2077)
- `ServerErrorPage.stories.tsx` — Storybook: `Default` с `MemoryRouter`, ссылка на макет «500» (1:2077)
- `ServerErrorPage.test.tsx` — Vitest: контракт с макетом (заголовок, описание, картинка, две кнопки), защита от копипаста текста 404, переход по «На главную», заглушка «Сообщить об ошибке». Прямой маршрут `/500` уже задан в RouterProvider; сценарий перехвата ошибки через `ErrorBoundary` остаётся в P8-01
