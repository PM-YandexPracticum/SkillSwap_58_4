# src/app/providers

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Провайдеры приложения подключают Redux, роутер, стартовую загрузку, уведомления и тему.

## Что внутри

- `RouterProvider.tsx` — все маршруты приложения, lazy-загрузка страниц, лейауты
- `DataProvider.tsx` — запускает загрузку пользователей, навыков, категорий и городов. Показывает Loader, открывает маршруты после загрузки и переводит на `/500` при ошибке
- `StoreProvider.tsx` — подключает Redux store к React
- `ThemeProvider.tsx` — Применяет сохранённую тему (`data-theme` на <html>) при старте приложения. ⭐ Необязательная фича (фаза 9): пока не реализована, просто отдаёт children
- `ToastProvider.tsx` — подключён в `App`, предоставляет `useToast` всем маршрутам. Выводит сообщения через портал в `body` в заранее смонтированной области `role="log"` / `aria-live="polite"`. У каждого сообщения свой таймер 4000 мс из `shared/config`; таймер отменяется и удаляется при закрытии, все активные таймеры очищаются при размонтировании
- `ToastProvider.module.css` — фиксированный список слева внизу, ширина 340 px по Figma. Длинный список прокручивается, оставляя сверху зону шапки (132 px); слой 5 находится ниже модального окна (10). Пустая область пропускает клики на страницу
- `ToastProvider.test.tsx` — показ через хук, live region, независимые таймеры, закрытие мышью и клавиатурой, очистка при размонтировании в StrictMode
- `ToastProvider.stories.tsx` — интерактивная story `app/providers/ToastProvider/Interactive` с настоящим провайдером и несколькими уведомлениями
- `ToastProvider.stories.module.css` — оформление демонстрации на CSS-переменных
