# src/app/router

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Вспомогательные компоненты маршрутизации, например защита приватных маршрутов.

## Текущее состояние

`RequireAuth` реализован (P4-08): гостя перенаправляет на `/login` с `state.from`, вошедшего пропускает.
`RegisterStepGuard` реализован (P6-01): если предыдущий шаг регистрации не пройден, перекидывает на `/register/step-1` с `replace`; пройденные шаги открываются свободно.

## Что внутри

- `RegisterDraftLifecycle.tsx` — наблюдатель внутри BrowserRouter, рядом с Routes. Единственное место автоматического сброса черновика: переход из `/register/*` на другой маршрут. Переходы между шагами и пробный cleanup StrictMode ничего не стирают.
- `RegisterDraftLifecycle.test.tsx` — общий сценарий лейаутов, store и guard: вперёд/назад, закрытие трёх шагов, выход по ссылкам, история, новая вкладка и StrictMode. Формы заменены тестовыми участниками контракта; их подключение — P6-02/04/05.

- `RegisterStepGuard.tsx` — Не пускает на шаг 2 или 3 регистрации без завершённого предыдущего шага. Если предыдущий шаг не пройден (`selectCompletedStep` < step − 1) — перенаправляет на `/register/step-1`. Состояние живёт только в памяти, поэтому после перезагрузки страницы прямой вход на шаг 2 или 3 снова ведёт на шаг 1
- `RegisterStepGuard.test.tsx` — прямой заход на шаги 2 и 3, пропуск после пройденных шагов, возврат на пройденный шаг
- `RequireAuth.tsx` — Защита приватных маршрутов `/profile/*` и `/favorites`. Гостя отправляет на `/login` через `replace`, сохраняя весь адрес в `state.from`, включая query и hash. Страница входа возвращает пользователя на этот адрес
- `RestoreSession.tsx` — после стартовой загрузки сверяет сохранённую сессию со списком пользователей и завершает её, если пользователя больше нет
- `RequireAuth.test.tsx` — 10 проверок: профиль, избранное и вложенная страница для гостя и вошедшего, query/hash, выход на закрытой странице, сохранённая сессия после создания нового store и возврат назад по истории
