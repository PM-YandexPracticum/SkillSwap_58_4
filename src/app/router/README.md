# src/app/router

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Вспомогательные компоненты маршрутизации, например защита приватных маршрутов.

## Текущее состояние

`RequireAuth` реализован (P4-08): гостя перенаправляет на `/login` с `state.from`, вошедшего пропускает.
`RegisterStepGuard` пока только возвращает `children` — редирект будет в P6-01.

## Что внутри

- `RegisterStepGuard.tsx` — Не пускает на шаг 2 или 3 регистрации по прямой ссылке: попасть туда можно только кнопками «Далее» / «Продолжить». Если предыдущий шаг не пройден (`selectCompletedStep` < step − 1) — перенаправляет на `/register/step-1`
- `RequireAuth.tsx` — Защита приватных маршрутов `/profile/*` и `/favorites`. Гостя отправляет на `/login` через `replace`, сохраняя весь адрес в `state.from`, включая query и hash. Возврат после входа подключается в P4-09
- `RequireAuth.test.tsx` — 10 проверок: профиль, избранное и вложенная страница для гостя и вошедшего, query/hash, выход на закрытой странице, сохранённая сессия после создания нового store и возврат назад по истории
