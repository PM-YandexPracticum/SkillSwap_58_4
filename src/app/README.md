# src/app

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../docs/architecture/fsd.md).

## Зачем эта папка

Слой **app** — точка сборки приложения: провайдеры, роутер, Redux store, лейауты и глобальные стили. Бизнес-логики здесь нет.

## Что внутри

- [`layouts/`](layouts/README.md) — Каркасы страниц: обычный (шапка, страница, подвал) и упрощённый для входа и регистрации (логотип и «Закрыть ×»)
- [`providers/`](providers/README.md) — React-провайдеры, которыми оборачивается всё приложение: Redux, роутер, уведомления, тема (необязательная фича)
- [`router/`](router/README.md) — Вспомогательные компоненты маршрутизации, например защита приватных маршрутов
- [`store/`](store/README.md) — Redux store: конфигурация, корневой редьюсер и глобальные типы `RootState` / `AppDispatch`
- [`test/`](test/README.md) — помощники для тестов: рендер компонента со store и роутером
- [`styles/`](styles/README.md) — Глобальные стили: CSS-переменные (цвета, отступы, шрифты) и reset
- `App.tsx` — корневой компонент: провайдеры + роутер + глобальные стили
- `App.test.tsx` — проверяет доступность уведомлений внутри дерева маршрутов
