# src/app/layouts

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Каркасы страниц: обычный (шапка, страница, подвал) и упрощённый для входа и регистрации (логотип и «Закрыть ×»).

## Что внутри

- `MainLayout.tsx` — готовые `Header` и `Footer`, между ними — `Outlet`. Контент ограничен токеном `--container-width` (1368 px) с боковыми отступами `--space-36`. На коротких страницах подвал прижат к низу окна, на длинных идёт после содержимого.
- `AuthLayout.tsx` — готовые `Logo` и `Button` «Закрыть» с декоративной иконкой. Для регистрации кнопка ведёт на главную с `replace`, для входа сохраняет `navigate(-1)`. Черновик очищает `RegisterDraftLifecycle` при выходе из маршрутов регистрации, логотип ведёт на главную. Контейнер `Outlet` занимает доступную ширину до `--container-width-narrow` (1136 px).
- `*.module.css` — размеры и расположение рамок на токенах проекта.
- `*.test.tsx` — проверки вложенных страниц, основной области, навигации и закрытия с клавиатуры через общий `renderWithProviders`.

На узком экране шапка AuthLayout допускает перенос кнопки закрытия на следующую строку, чтобы оба действия оставались доступны без горизонтального скролла. Вход и регистрация используют общую область `main` из `shared/ui/AuthPageLayout`.

## Границы ответственности

Лейауты отвечают за рамки и вывод вложенных маршрутов. Единственный `<main>` и заголовок `<h1>` предоставляет страница; формы, иллюстрации и Stepper также остаются в страницах входа и регистрации.

Поиск подключён внутри готового `Header` к слайсу `search` в P5-03; применённый запрос сохраняется при переходах между лейаутами. Данные сессии и выход подключаются в P5-09, уведомления — в P7-05. Меню категорий подключено в P3-06; панель уведомлений предстоит передать в P7-05. Содержимое передаётся в готовые слоты `Header` из app-слоя, без импорта соседних виджетов друг в друга.

Отдельные stories для `app/layouts` правила проекта не требуют. Геометрию проверяем в браузере по Figma: каталог `1:2861`, вход `1:2400`, первый шаг регистрации `1:2548`.
