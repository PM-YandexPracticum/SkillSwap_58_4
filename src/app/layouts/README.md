# src/app/layouts

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Каркасы страниц: обычный (шапка, страница, подвал) и упрощённый для входа и регистрации (логотип и «Закрыть ×»).

## Текущее состояние

Оба лейаута пока выводят только `Outlet`. Header, Footer, Logo и кнопку закрытия подключаем в P3-05. Header (P3-04) и Footer (P3-03) уже готовы и влиты в `develop`. Ниже — состав лейаутов после реализации.

## Что внутри

- `AuthLayout.tsx` — Лейаут экранов входа и регистрации: только Logo и кнопка «Закрыть ×», без шапки и подвала
- `MainLayout.tsx` — Основной лейаут: Header + контент страницы + Footer. Используется для каталога, навыка, профиля, избранного, «О проекте»
