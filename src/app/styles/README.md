# src/app/styles

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Глобальные стили: CSS-переменные (цвета, отступы, шрифты), светлая и тёмная палитры и reset.

## Что внутри

- [`fonts/`](fonts/README.md) — шрифты проекта (Jost, Open Sans, Roboto) — локальные файлы WOFF2, не Google Fonts
- `fonts.css` — `@font-face` для шрифтов из `fonts/`; подключён в начале `global.css`
- `global.css` — глобальные стили, CSS-переменные и `[data-theme='dark']` палитра

`--color-overlay` — цвет затемнения Modal; `--shadow-image-action` — тень кнопки поверх фотографии.
Компоненты используют семантические переменные вместо собственных числовых цветов.

Слои поверх страницы заданы общими токенами: `--z-popover` (100),
`--z-modal` (200), `--z-toast` (300). Поэтому выпадающее меню не перекрывает
модальное окно, а сообщения остаются видны поверх него. Локальные слои
внутри компонента (например, стрелки карусели) не заменяют эти токены.
