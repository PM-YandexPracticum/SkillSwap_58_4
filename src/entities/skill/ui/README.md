# src/entities/skill/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `SkillGallery.tsx` — общая галерея SkillInfo и окна регистрации: одно фото без карусели, несколько — Carousel и до трёх миниатюр с «+N». Получает только название и адреса, не читает store и файлы.
- `SkillGallery.module.css` — единые размеры фото и миниатюр, отступы и фокус клавиатуры.
- `SkillGallery.test.tsx`, `SkillGallery.stories.tsx` — пустая галерея, одно и несколько фото, остаток и переключение миниатюрой.
- `SkillInfo.tsx` — Блок описания навыка: своё название, «Категория / Подкатегория», описание. Названия категории и подкатегории — пропсами `categoryTitle` / `subcategoryTitle`, кнопки — слотом `actions` (P3-02)
- `SkillTag.tsx` — чип навыка или подкатегории в цвете своей категории: `title` и `categoryId`. Обёртка над `shared/ui/Tag`
- `SkillTag.test.tsx` — тесты: цвет категории, незнакомая категория

Галерея в SkillInfo и SkillPreviewModal переиспользует `SkillGallery`. Фотографии проходят через `resolveImageUrl` и имеют alt с названием навыка и номером.
У миниатюр остаётся пустой alt: это изображение внутри кнопки с собственным `aria-label` «Показать фото N»;
повторный текст изображения только дублировал бы имя действия.

Если `images` пуст, `SkillInfo` показывает общую заглушку через `resolveImageUrl`;
для одного изображения карусель и миниатюры не нужны. Если внутри карточки не хватает места
для двух колонок, галерея переносится под текст. Это сохраняет исходный вид на широком
десктопе и убирает горизонтальную прокрутку на более узком окне.
