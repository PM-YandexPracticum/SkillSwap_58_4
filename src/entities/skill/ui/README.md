# src/entities/skill/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `SkillInfo.tsx` — Блок описания навыка: своё название, «Категория / Подкатегория», описание. Названия категории и подкатегории — пропсами `categoryTitle` / `subcategoryTitle`, кнопки — слотом `actions` (P3-02)
- `SkillTag.tsx` — чип навыка или подкатегории в цвете своей категории: `title` и `categoryId`. Обёртка над `shared/ui/Tag`
- `SkillTag.test.tsx` — тесты: цвет категории, незнакомая категория

Фотографии галереи проходят через `resolveImageUrl` и имеют alt с названием навыка и номером.
У миниатюр остаётся пустой alt: это изображение внутри кнопки с собственным `aria-label` «Показать фото N»;
повторный текст изображения только дублировал бы имя действия.
