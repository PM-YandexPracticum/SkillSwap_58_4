# src/entities/skill/api

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **api** слайса `skill` — единственное место, которое знает, откуда берутся данные (сейчас — «база» `shared/api/mock-db`). Переход на настоящую БД — меняется только этот сегмент.

## Что внутри

- `skillApi.ts` — Хранилище навыков. Единственное место, которое знает, откуда берутся данные. Переход на настоящую БД — меняется только этот файл

`getSkillById`, `createSkill` и `updateSkill` дают сценарию регистрации точечное чтение и повторяемую запись по стабильному id; общую коллекцию заново загружать не нужно.

API передаёт runtime-валидатор сущности в `loadSeed` и `createMockCollection`:
обязательные поля и вложенные массивы проверяются до передачи JSON в Redux.
Неверные сохранённые данные сбрасываются к образцам; неверный seed даёт ошибку загрузки с повторной попыткой.
