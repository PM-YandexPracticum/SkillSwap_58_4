# src/entities

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../docs/architecture/fsd.md).

## Зачем эта папка

Слой **entities** — бизнес-сущности предметной области: типы, Redux-слайсы, селекторы, загрузка данных и «глупый» UI.

## Что внутри

- [`category/`](category/README.md) — Категории и подкатегории навыков («Творчество и искусство» → «Музыка и звук»)
- [`city/`](city/README.md) — Справочник городов (~15) — простая сущность: id и название
- [`exchange/`](exchange/README.md) — Предложение обмена (номинальное): кто, кому и на какой навык предложил
- [`notification/`](notification/README.md) — Уведомления в колокольчике шапки: «Вы предложили обмен …» → «Перейти»; новые и просмотренные
- [`session/`](session/README.md) — Сессия текущего пользователя (мок-авторизация через localStorage): кто вошёл и вошёл ли вообще
- [`skill/`](skill/README.md) — Навык, которым пользователь готов поделиться: название, категория, описание, фото
- [`user/`](user/README.md) — Пользователь платформы: профиль, город, возраст, чему может научить и чему хочет научиться

## Правило импортов

Сущность импортирует только shared. Другие сущности — только типы (`import type`).
