# src/entities/notification/api

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **api** слайса `notification` — единственное место, которое знает, откуда берутся данные (сейчас — «база» `shared/api/mock-db`). Переход на настоящую БД — меняется только этот сегмент.

## Что внутри

- `notificationApi.ts` — `getNotifications()`, `createNotification(notification)`, `markNotificationRead(id)`, `markAllNotificationsRead(userId)` и `clearNotifications(userId)`. Массовые действия затрагивают только указанного владельца; очистка удаляет и новые, и просмотренные записи. Чтение всех возвращает полный список владельца, включая уже просмотренные записи. Создание, чтение и массовые действия выполняются в очереди, чтобы не перемешиваться.
- `notificationApi.test.ts` — разделение по владельцам, повторное чтение, очистка пустого списка и сохранение нового уведомления, пришедшего после очистки.

Функции API работают с переданными данными. Компоненты вызывают thunks из публичного API слайса: они определяют владельца по сессии и синхронизируют Redux с базой.
