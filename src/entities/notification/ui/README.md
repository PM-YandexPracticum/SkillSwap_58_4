# src/entities/notification/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `notification` — React-компоненты. Строка уведомления получает данные и обработчик через пропсы; подключение к store выполняется выше в P7-05.

## Что внутри

- `NotificationItem.tsx` — строка уведомления: иконка, «Вы предложили обмен {userName}», дата и кнопка «Перейти». Кликабельна только кнопка, у прочитанного её нет; клик передаётся наружу через `onGo`. У кнопки доступное имя «Перейти — Вы предложили обмен Ивану» (скрытый `span`), видимый текст — «Перейти». `userName` передаётся уже в нужной форме («Ивану», «Анне») — компонент не склоняет. Figma: 1:2190 (окно уведомлений), 1:2148 (экран с открытой панелью).
- `NotificationItem.module.css` — стили строки, в том числе `.visuallyHidden` для текста, доступного только скринридеру.
- `NotificationItem.test.tsx` — тесты Vitest + Testing Library: имя получателя, форматированная дата, наличие и отсутствие кнопки по `isRead`, вызов `onGo` по клику, доступное имя кнопки с текстом уведомления.
- `NotificationItem.stories.tsx` — stories Storybook: `Unread` (с кнопкой) и `Read` (без кнопки); данные из общей фабрики `createNotification()` через `../testing`. `userName` — готовая форма «Ивану». Figma: 1:2190.
