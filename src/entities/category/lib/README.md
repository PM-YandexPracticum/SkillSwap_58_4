## Зачем эта папка

Сегмент **lib** слайса `category` — чистые функции без React и Redux. Используются компонентами и селекторами; проверяются unit-тестами.

**Текущее состояние:** `createCategory`, `findSubcategories` и правила связи списков `linkCategories` реализованы.

## Правило связи категорий и подкатегорий (ТЗ п. 3.3)

1. Выбраны категории — в списке подкатегорий только их подкатегории.
2. Ничего не выбрано — видны все подкатегории.
3. Выбрана подкатегория — её категория отмечается автоматически.
4. Снятая категория убирает свои подкатегории; выбор остальных категорий сохраняется.
5. Шаг 2 использует множественный выбор, шаг 3 — одиночный. В обоих случаях значения передаются массивами; в режиме `single` — не более одного id в каждом массиве.

При действии пользователя `syncCategorySelection` удаляет отсутствующие в загруженном справочнике id и повторы. Пустой справочник может означать незавершённую загрузку, поэтому значения сохраняются до получения данных. Компонент не меняет управляемые значения сам при обновлении props. Загрузкой, черновиком и обязательностью полей занимаются вызывающие формы.

## Что внутри

- `createCategory.ts` — фабрика категорий для тестов и stories; импорт через `@/entities/category/testing`.
- `linkCategories.ts` — правила связывания:
  - `getAvailableSubcategories(categories, selectedCategoryIds)` возвращает все подкатегории при пустом выборе категорий, иначе — только подкатегории выбранных. Если все выбранные id устарели, доступны все подкатегории для нового выбора.
  - `syncCategorySelection(categories, selection, previous)` согласует новый выбор с прежним. Аргумент `previous` отличает снятие категории от выбора подкатегории без категории: новый выбор в этих случаях может совпадать.
- `linkCategories.test.ts` — фильтрация, автовыбор категории, снятие и смена категории, пустой справочник, неизвестные id, повторы и отсутствие мутаций.
- `findSubcategories.ts` — поиск подкатегорий в порядке выбранных id; отсутствующие записи пропускаются. Используется для интересов автора и связи списков.
- `findSubcategories.test.ts` — порядок выбора, отсутствующие id и пустые списки.
