# src/entities/category/api

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **api** слайса `category` — единственное место, которое знает, откуда берутся данные (сейчас — «база» `shared/api/mock-db`). Переход на настоящую БД — меняется только этот сегмент.

## Что внутри

- `categoryApi.ts` — Хранилище категорий и подкатегорий. Единственное место, которое знает, откуда берутся данные. Переход на настоящую БД — меняется только этот файл
