# src/entities/category/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `category` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** CategoryIcon реализована (P3-06). CategorySubcategorySelect реализует пару списков
в режимах multiple и single (P3-12) и связь категорий с подкатегориями (P6-03).

## Что внутри

- `CategoryIcon.tsx` — декоративная SVG из shared/assets, круг 40 px и иконка 24 px; цвет — семантический id категории, неизвестные значения безопасны
- `CategoryIcon.module.css` — размеры и цвета из токенов проекта
- `CategoryIcon.test.tsx` — шесть иконок и неизвестные значения
- `CategoryIcon.stories.tsx` — все категории и запасное нейтральное состояние
- `CategorySubcategorySelect.tsx` — пара списков категорий и подкатегорий в режимах `multiple` и `single`;
  категории и выбранные значения получает пропсами, Redux не подключает. Подкатегории фильтруются
  через `getAvailableSubcategories` из `../lib/linkCategories`, а изменение любой части выбора проходит
  через `syncCategorySelection`: выбор подкатегории отмечает её категорию, снятие категории убирает
  её подкатегории. Пустой справочник и обновление props не сбрасывают управляемое значение;
  при действии пользователя неизвестные id из загруженного справочника удаляются.
- `CategorySubcategorySelect.test.tsx` — оба режима, фильтрация, автовыбор и снятие категории,
  загрузка справочника, неизвестные id и управляемое значение.
- `CategorySubcategorySelect.stories.tsx` — закрытые и раскрытые списки, заполнение, ошибка, настоящие справочники,
  одиночный выбор и взаимодействие связанных списков.
