# src/entities/user/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `user` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `UserCard.tsx` — Карточка пользователя: аватар, имя, «город, возраст», «Может научить» (один чип — своё название навыка), «Хочет научиться» (чипы подкатегорий, лишние — «+N»). Сама ничего не «делает»: лайк со счётчиком и «Подробнее» приходят через слоты. Блок «аватар + имя + город, возраст» переиспользуется в UserProfileCard
- `UserProfileCard.tsx` — Расширенная карточка автора на странице навыка: аватар, имя, город/возраст, «О себе», теги
