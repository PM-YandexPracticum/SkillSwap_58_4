# src/entities/user/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `user` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `UserCard.tsx` — карточка пользователя по макету (1:2877): аватар, имя, «город, возраст», «Может научить» (один чип), «Хочет научиться» (до двух чипов и «+N»). Город, навык и подкатегории приходят пропсами (`cityName`, `teachSkill`, `learnSubcategories`) — их собирает виджет карточки предложения (P3-08); лайк и «Подробнее» — слоты `topAction` и `bottomAction`. Длинные названия чипов обрезаются многоточием, «+N» виден всегда
- `UserCard.module.css` — стили карточки на токенах
- `UserCard.test.tsx` — тесты: имя, «город, возраст» со склонением, чипы и «+N», слоты
- `UserCard.stories.tsx` — как в макете, с двумя подкатегориями, без фото, без слотов, с самыми длинными названиями из данных и «Из базы» — Иван (`u01`) с настоящими данными из `public/db`; там же показано, как собрать пропсы карточки из данных
- `UserSummary.tsx` — блок «аватар + имя + город, возраст» со слотом лайка; общий для UserCard и UserProfileCard (P3-02). Длинные имя и город обрезаются многоточием
- `UserSummary.module.css` — стили блока; место под лайк — только у строки с именем, как в макете
- `UserProfileCard.tsx` — Расширенная карточка автора на странице навыка: аватар, имя, город/возраст, «О себе», теги
