# src/features/avatar-upload/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `avatar-upload` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** `AvatarUpload` готов (P3-12 вёрстка, P6-04 выбор и проверка файла). Компонент отображает аватар или иконку-заглушку 56 px в рамке 72 px и кнопку «+», которая открывает выбор файла. Фото хранит тот, кто использует компонент: черновик регистрации (P6-04) или личные данные (P7-06).

## Что внутри

- `AvatarUpload.tsx` — Аватар регистрации (1:1497): кнопка «+» открывает выбор файла (jpg, png, webp). `validateImageFile` проверяет тип и размер, `fileToDataUrl` уменьшает фото до 800 px, `onChange(dataUrl)` отдаёт готовый data URL (`File` наружу не выходит); ошибка файла («Только JPG, PNG или WEBP» / «Файл больше 1 МБ» / «Не удалось загрузить фото…») показывается под аватаром, пока файл читается, кнопка недоступна. Пропсы: `value`, `onChange`, `error`, `disabled`
- `AvatarUpload.module.css` — размеры рамки, иконки, фото, кнопки и текста ошибки.
- `AvatarUpload.test.tsx` — подпись кнопки, выбор файла, три формата, ошибки типа, размера и чтения, состояние загрузки, внешняя ошибка и `disabled`.
- `AvatarUpload.stories.tsx` — без фото, с фото и с ошибкой.
