# src/features/avatar-upload/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `avatar-upload` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** в рамках P3-12 реализована базовая вёрстка `AvatarUpload`. Компонент отображает аватар или иконку-заглушку 56 px в рамке 72 px и кнопку «+». Обработка выбора, проверки и сохранения файла — P6-04.

## Что внутри

- `AvatarUpload.tsx` — вёрстка аватара регистрации (1:1497); фото отображается общим Avatar. Выбор и обработка файла — P6-04; вариант личных данных — P3-14.
- `AvatarUpload.module.css` — размеры рамки, иконки, фото и кнопки.
- `AvatarUpload.test.tsx` — подпись кнопки и смена переданного фото.
- `AvatarUpload.stories.tsx` — без фото и с переданным фото.
