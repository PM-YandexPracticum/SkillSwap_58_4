# Интерфейс загрузки аватара

- `AvatarUpload.tsx` — общий выбор, проверка и чтение файла для регистрации и профиля. Пропсы: `value`, `onChange`, `variant`, `alt`, `onProcessingChange`, `error`, `disabled`. Допустимы JPG, PNG и WEBP до 1 МБ; результат — уменьшенный до 800 px data URL.
- `AvatarUpload.module.css` — оформление двух вариантов: регистрация 1:1497 и профиль 1:2370. Ошибка остаётся снаружи круглого фото и не обрезается.
- `AvatarUpload.test.tsx` — выбор и повтор файла, доступные подписи, поддерживаемые форматы, ошибки, блокировка и завершение чтения после размонтирования.
- `AvatarUpload.stories.tsx` — без фото, с фото, с ошибкой и крупный вариант профиля.

Фото отображает общий Avatar. Файл не проверяется и не сжимается повторно в потребителях. Компонент только отдаёт значение: черновиком регистрации управляет страница регистрации, сохранением профиля — единая форма `profile-edit`.
