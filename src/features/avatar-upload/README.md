# src/features/avatar-upload

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Загрузка и смена аватара (сохраняется как data URL).

**Текущее состояние:** вёрстка аватара второго шага готова (P3-12). Выбор файла, проверка и сохранение — P6-04. В кабинете Avatar и кнопка изменения уже свёрстаны в P3-14; их рабочую загрузку подключает P7-06.

## Что внутри

- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
