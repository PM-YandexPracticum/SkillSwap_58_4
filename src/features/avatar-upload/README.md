# src/features/avatar-upload

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Загрузка и смена аватара (сохраняется как data URL).

**Текущее состояние:** аватар второго шага готов (P3-12, P6-04): кнопка «+» открывает выбор файла, `validateImageFile` проверяет тип и размер, `fileToDataUrl` уменьшает фото до 800 px, `onChange` отдаёт готовый data URL; ошибка показывается под аватаром. Сохранение в черновик регистрации делает страница. `onProcessingChange` сообщает форме о чтении; после размонтирования поздний результат или ошибка не вызывают callbacks. В кабинете Avatar и кнопка изменения уже свёрстаны в P3-14, подключить к ним этот компонент и сохранение — P7-06.
