# Загрузка аватара

`AvatarUpload` принимает сохранённое фото через `value` и возвращает обработанный data URL через `onChange`. Тип и размер проверяет общий `validateImageFile`, уменьшение до 800 px выполняет `fileToDataUrl`. Компонент не сохраняет данные в store или базу.

Два варианта используют одну обработку файлов:

- `registration` по умолчанию — рамка 72 px, фото или иконка 56 px и кнопка «+» для второго шага регистрации.
- `profile` — фото 244 px и кнопка редактирования 56 px для личных данных. Если фото нет, показывается общая заглушка Avatar.

`onProcessingChange` сообщает форме о чтении файла; `disabled` блокирует выбор во время сохранения. Ошибка показывается под фото и связана с кнопкой. После размонтирования поздний результат не вызывает callbacks.

[ui/](ui/README.md) содержит компонент, стили, тесты и истории. Архитектура — [FSD](../../../docs/architecture/fsd.md).
