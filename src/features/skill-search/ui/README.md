# src/features/skill-search/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill-search` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `SearchInput.tsx` — Поле «Искать навык» в шапке с иконкой лупы слева (как в макете). Поиск запускается по Enter или по клику на лупу — лупа работает как кнопка (подпись для скринридера «Искать»). Когда в поле есть текст — справа крестик «×»: очищает поле и сбрасывает поиск, каталог возвращается к секциям
