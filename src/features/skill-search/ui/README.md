# src/features/skill-search/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill-search` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `SearchInput.tsx` — поле «Искать навык» в шапке с лупой слева. Поиск запускается по Enter или клику на лупу (подпись «Искать»); когда в поле есть текст — справа крестик «×», он очищает поле. Применённый запрос хранится в `searchSlice`, а набираемый черновик — локально; внешние `queryApplied` и `queryCleared` синхронизируют поле без повторного вызова `onSearch` / `onClear`
- `SearchInput.module.css` — положение лупы и отступы поля
- `SearchInput.stories.tsx` — пустое поле, с текстом, очистка крестиком
- `SearchInput.test.tsx` — тесты поиска по Enter и по лупе, очистки с клавиатуры, начального текста и внешних команд, включая повторный сброс

## Контракт поля

`defaultValue` задаёт только начальный черновик и не применяет поиск. В Redux запрос попадает после Enter или клика по лупе; пустой запрос и пробелы по краям обрабатывает `queryApplied`. Крестик вызывает `queryCleared`, скрывается и возвращает фокус в поле. Внешние команды также заменяют черновик, даже если применённая строка не изменилась. Другие изменения store не затрагивают ввод.

Компонент требует Redux Provider. В тестах используем общий `renderWithProviders`, в stories — отдельный store со слайсом `search`. `onSearch` и `onClear` — дополнительные уведомления о действиях пользователя, запись в Redux уже выполняется внутри поля.
