# src/features/skill-search

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Поиск из поля «Искать навык» в шапке: запуск по Enter или клику на лупу, «×» очищает.

## Что внутри

- [`model/`](model/README.md) — типы, слайс, селекторы
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда

## Подключение

`SearchInput` подключён к слайсу `search` через типизированные хуки. `queryApplied`, `queryCleared`, `selectSearchQuery` и `selectIsSearchActive` доступны через публичный API. Внешний сброс синхронизирует поле; черновик до подтверждения не влияет на каталог.

Фильтрацию по названию предлагаемого навыка выполняет готовая `applyFilters` из `catalog-filter`. Обе фичи связывает страница каталога, без импорта соседних фич друг в друга. Список, счётчик «Подходящие предложения: N» и пустая выдача подключаются в P3-10/P5-05 с данными P4-03.
