# src/features/logout/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `logout` — React-компоненты. Получают данные пропсами или из store через селекторы.

`LogoutButton` сразу вызывает `endSession()` и переводит на главную с заменой записи истории. Очистка store и localStorage не зависит от размонтирования кнопки или загрузки главной; данные пользователей, навыков, лайков и обменов сохраняются.

Основной роутер и тестовый помощник используют `useTransitions={false}`, чтобы синхронная очистка Redux и новый адрес применялись вместе. Это исключает промежуточный переход `RequireAuth` на `/login` без таймеров, cleanup и `flushSync`. Проверки включают выход с публичной и закрытых страниц, а также медленную lazy-загрузку главной.

## Что внутри

- `LogoutButton.tsx` — выход с переходом на главную и очисткой сессии в store и localStorage.
- `LogoutButton.test.tsx` — выход, сохранение базы, история и обычное удаление кнопки.
- `LogoutButton.stories.tsx` — работа кнопки в роутере и Redux.
