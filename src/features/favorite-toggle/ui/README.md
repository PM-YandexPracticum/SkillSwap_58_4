# src/features/favorite-toggle/ui

Кнопка лайка на карточке предложения: показывает активное состояние из `likedUserIds` и переданный родителем счётчик и блокируется на время сохранения этого адресата. Выбранное сердечко заполнено готовой иконкой `like-filled.svg`. Ошибку показывает общий Toast; поздний ответ после смены адресата, сессии или размонтирования не показывает уведомление. Гость переходит на вход с исходным адресом возврата, владелец карточки не может лайкнуть себя.

## Что внутри

- `FavoriteButton.tsx` — сердечко с доступным состоянием и счётчиком `likesCount`.
- `FavoriteButton.module.css` — оформление сердечка со счётчиком рядом.
- `FavoriteButton.test.tsx` — проверяет маршрут возврата гостя, запрет лайка себе, сохранение/снятие лайка, ошибку, повтор и смену сессии.
- `FavoriteButton.stories.tsx` — гость, выбранное состояние, сохранение, собственная карточка и значения счётчика; decorator предоставляет Redux, роутер и контекст Toast. В stories виджетов сообщения Toast отключены, чтобы изолированная витрина не создавала внешние уведомления.
