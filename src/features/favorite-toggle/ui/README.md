# src/features/favorite-toggle/ui

Кнопка лайка на карточке предложения: показывает активное состояние из `likedUserIds`, обновляет счётчик и блокируется на время сохранения. Гость переходит на вход с исходным адресом возврата, владелец карточки не может лайкнуть себя.

## Что внутри

- `FavoriteButton.tsx` — сердечко с доступным состоянием и счётчиком `likesCount`.
- `FavoriteButton.module.css` — оформление сердечка со счётчиком рядом.
- `FavoriteButton.test.tsx` — проверяет возврат гостя после входа и запрет лайка себе.
- `FavoriteButton.stories.tsx` — обычное, нулевое и большое значение счётчика.
