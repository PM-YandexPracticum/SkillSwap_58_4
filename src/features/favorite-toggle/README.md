# src/features/favorite-toggle

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Лайк: сердечко со счётчиком. Меняет `likedUserIds` текущего пользователя и `likesCount` того, кого лайкнули.

Клик по сердечку добавляет или удаляет id в `likedUserIds` текущего пользователя и меняет `likesCount` адресата. Обе записи сохраняются через операции `entities/user`; при ошибке второй записи первая компенсируется. Гость переходит на вход с адресом возврата, а пользователь не может поставить лайк себе.
