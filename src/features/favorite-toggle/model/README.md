# src/features/favorite-toggle/model

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **model** слайса `favorite-toggle` — данные и логика: типы, Redux-слайс, селекторы, схемы валидации.

## Что внутри

- `selectors.ts` — id пользователей в избранном у текущего пользователя (`likedUserIds`). Гость — пустой массив. Используется на странице «Избранное» и в сердечке на карточке
- `toggleFavorite.ts` — Лайк / снятие лайка. Своего хранилища у избранного нет. Меняются два пользователя (без мутаций — новые объекты): - у текущего пользователя `likedUserIds` (+ id / − id) — из этого строится страница «Избранное»; - у того, кого лайкнули, `likesCount` (+1 / −1) — это счётчик на карточке и сортировка «Популярного». Оба изменения сохраняются через `updateUser` из entities/user; если не получилось — откатить
