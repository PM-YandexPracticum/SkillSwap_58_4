# src/features/theme-toggle

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Переключение светлой / тёмной темы — дополнительная фича фазы 9.

**Текущее состояние:** реализация подключена в проекте: выбор следует системной настройке при первом визите,
сохраняется в `localStorage`, синхронизируется между вкладками и меняет семантические CSS-токены. Флаг
`FEATURE_FLAGS.DARK_THEME` управляет отображением переключателя и подпиской на системную тему.

## Что внутри

- [`model/`](model/README.md) — публичный хук, делегирующий общему источнику темы
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
