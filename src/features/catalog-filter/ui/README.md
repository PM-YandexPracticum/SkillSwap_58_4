# src/features/catalog-filter/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `catalog-filter` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `ActiveFilters.tsx` — Ряд плашек выбранных фильтров над результатами («Москва ×», «Фотография ×», «Женский ×»): крестик снимает один фильтр
- `CityFilter.tsx` — Чекбоксы «Город» из справочника entities/city: первые `CATALOG.CITIES_VISIBLE` видны сразу, остальные — по «Все города ▾»
- `GenderFilter.tsx` — Радио «Пол автора»: Не имеет значения / Мужской / Женский
- `ModeFilter.tsx` — Радио «Всё / Хочу научиться / Могу научить»
- `ResetFiltersButton.tsx` — Кнопка «Сбросить ×» рядом с «Фильтры (N)»
- `SkillsFilter.tsx` — Дерево чекбоксов «Навыки»: категория раскрывается в подкатегории, «Все категории» показывает остальные
- `SortToggle.tsx` — Переключатель сортировки результатов «Сначала новые» ⇄ «Сначала старые» (по дате регистрации)
