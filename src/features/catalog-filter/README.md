# src/features/catalog-filter

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Фильтры каталога: «Всё / Хочу научиться / Могу научить», навыки, пол автора, город, сортировка, плашки выбранного. Комбинируются логикой AND.

## Что внутри

- [`lib/`](lib/README.md) — чистые функции
- [`model/`](model/README.md) — типы, слайс, селекторы
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда

## Готово в P5-01

Реализованы Redux-действия фильтров и чистая функция `applyFilters`, покрытые тестами. Семантика режимов и поиск описаны в [`lib/README.md`](lib/README.md), действия и счётчик — в [`model/README.md`](model/README.md). Загрузка пользователей не требуется для выполнения unit-тестов: используются фабрики. UI подключается отдельными задачами P5-02 и P5-05.

## Вёрстка P3-07 и подключение P5-02

Реализованы пять компонентов левой панели и внутренний `SkillsCategory`. Они переиспользуют UI-кит; P5-02 подключает выборы и общий сброс к `catalogFilter` в store. Правила раскрытия, доступности, stories и границы ответственности описаны в [`ui/README.md`](ui/README.md).
