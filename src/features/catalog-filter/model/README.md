# src/features/catalog-filter/model

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **model** слайса `catalog-filter` — данные и логика: типы, Redux-слайс, селекторы, схемы валидации.

## Что внутри

- `catalogFilterSlice.ts` — Фильтры каталога. Когда выбран хотя бы один фильтр или введён поиск — секции «Популярное / Новое / Рекомендуем» заменяются на «Подходящие предложения: N»: плашки фильтров, сортировка и лента с догрузкой. Действия `setMode`, `toggleSubcategory`, `toggleCategory`, `setGender`, `toggleCity`, `setSort`, `removeFilter`, `resetFilters` меняют состояние без мутаций снаружи Redux.
- `selectors.ts` — Текущие фильтры
- `types.ts` — Радио-группа «Всё / Хочу научиться / Могу научить»

## Использование

Действия и селекторы импортируем из `@/features/catalog-filter`. `toggleCategory(subcategoryIds)` принимает id всех подкатегорий категории: при частичном выборе добавляет недостающие, при полном снимает только эту категорию. Пустой список ничего не меняет, повторяющиеся id не добавляются.

`removeFilter({ type: 'subcategory' | 'city', id })` снимает одно значение; `{ type: 'mode' | 'gender' | 'sort' }` сбрасывает соответствующий параметр. `resetFilters()` возвращает исходные значения, включая сортировку `newest`. Поиск хранится в отдельной фиче: очистку запроса вместе с фильтрами координирует вызывающий код, без импорта соседней фичи сюда.

Счётчик учитывает режим, каждую подкатегорию, пол и каждый город; сортировка не увеличивает его. Подключение UI к store — P5-02. Проверки: `catalogFilterSlice.test.ts`, `selectors.test.ts`.
