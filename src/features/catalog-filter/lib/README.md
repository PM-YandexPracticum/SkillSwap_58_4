# src/features/catalog-filter/lib

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **lib** слайса `catalog-filter` — чистые вспомогательные функции. Первые кандидаты на unit-тесты.

## Что внутри

- `applyFilters.ts` — Чистая функция фильтрации каталога. Не мутирует входной массив. Правило из ТЗ: все фильтры и поиск комбинируются логикой AND; внутри одного блока несколько отмеченных значений — «любой из» (иначе два города дают пустой результат). Учитывает режим («Хочу научиться» — по `learnSubcategoryIds`, «Могу научить» — по подкатегории навыка), подкатегории, пол, города, строку поиска (по названию навыка и подкатегориям) и сортировку по `createdAt`. Обязательно покрыть unit-тестами — это ядро бизнес-логики каталога
