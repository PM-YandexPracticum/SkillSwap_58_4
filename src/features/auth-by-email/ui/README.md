# src/features/auth-by-email/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `auth-by-email` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** форма — заготовка P3-11; вход и возврат на исходный адрес — P4-09. `login()` пока бросает `Not implemented`. Описания ниже задают целевую ответственность файлов.

## Что внутри

- `LoginForm.tsx` — форма входа: Email, Пароль (с глазом), кнопка «Войти», ссылка «Зарегистрироваться». Пока вёрстка на react-hook-form: по «Войти» отдаёт значения в `onSubmit`, общая ошибка входа приходит пропом `error` (оба поля красные, текст под паролем). Правила полей и проверку пары email/пароль подключит P4-09. Кнопки Google / Apple над формой ставит страница
- `LoginForm.module.css` — стили формы
- `LoginForm.stories.tsx` — пустая форма (1:2400) и неверные данные (1:2473)
- `LoginForm.test.tsx` — тесты: поля, отправка, общая ошибка и aria, порядок фокуса
