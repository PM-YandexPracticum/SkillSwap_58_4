# src/features/profile-edit/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `profile-edit` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** вёрстка ProfileForm готова в P3-14 (PR #183): Input, Textarea, Select, локальные демонстрационные значения и кнопки. Города читаются из Redux. Форма пока не использует данные текущего пользователя, схему и сохранение; действия «Изменить пароль» / «Сохранить» подключает P7-06.

## Что внутри

- `ProfileForm.tsx` — Вёрстка «Личные данные»: Почта, кнопка «Изменить пароль», Имя, Дата рождения (Input type="date"), Пол, Город, «О себе», «Сохранить». Редактирование полей локальное; смена пароля, валидация и сохранение пока не подключены
