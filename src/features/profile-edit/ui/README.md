# Интерфейс редактора профиля

`ProfileForm.tsx` показывает почту, дополнительное поле нового пароля, имя, DatePicker, пол, город, «О себе» и кнопку сохранения. Пол допускает «Не указан». Компонент использует общие Input, Select, Textarea, PasswordInput и Button; иконка редактирования берётся из общего набора.

Поведение находится в `model/useProfileForm.ts`, состояние полей — в React Hook Form. Ошибки показываются после ухода с поля и обновляются при исправлении. Поля передают ref для фокуса на ошибке; переключатель пароля сообщает раскрытое состояние, форма — состояние занятости.

Фото подключает страница через `avatarUpload`: слот получает значение, обработчик выбора, состояние блокировки и callback чтения файла. Значение фото входит в ту же форму, что и остальные поля; отдельного черновика у страницы нет.

`ProfileForm.module.css` задаёт две колонки по Figma 1:2370. `ProfileForm.stories.tsx` показывает форму с общим store. Интеграционные сценарии сохранения и фото находятся рядом со страницей в `ProfilePersonal.test.tsx`.

Текст «Изменить пароль» локально затемнён смешением общих токенов, как ссылка FileDropzone: исходный акцент не обеспечивал контраст 4.5:1 для текста 16 px. Глобальная палитра не меняется.
