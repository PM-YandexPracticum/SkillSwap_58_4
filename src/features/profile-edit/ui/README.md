# src/features/profile-edit/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `profile-edit` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** форма пока возвращает `null` (P3-14), схема содержит только заготовленные правила; сохранение — P7-06. Описания ниже задают целевую ответственность файлов.

## Что внутри

- `ProfileForm.tsx` — Форма «Личные данные»: Почта, «Изменить пароль» (по клику появляется дополнительное поле нового пароля — не модалка), Имя, Дата рождения, Пол, Город, «О себе» (изначально пустое; заполненное — показывается в карточке автора), «Сохранить»
