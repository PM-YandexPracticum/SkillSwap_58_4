# Редактирование профиля

`ProfileForm` редактирует личные данные текущего пользователя и сохраняет их через `updateDataUser`. Города читает из общего store; пользователя и слот загрузчика фото передаёт страница `ProfilePersonal`.

Поля и аватар входят в одну форму React Hook Form. Общие правила Yup проверяют email, имя, возраст, город, текст и новый пароль. Сохранение доступно после изменений и успешной проверки. Ошибка оставляет ввод; успех обновляет исходные значения формы. Фоновые изменения лайков не сбрасывают черновик.

- [model/](model/README.md) — схема, преобразование данных и управление формой.
- [ui/](ui/README.md) — поля, ошибки и расположение формы.
- `index.ts` — публичный API компонента и базовой схемы профиля.

Загрузчик подключается через слот, поэтому `profile-edit` не импортирует соседний feature `avatar-upload`. Страница задаёт `key` из id пользователя и токена сессии: при смене пользователя или сессии пересоздаётся весь редактор. Архитектура — [FSD](../../../docs/architecture/fsd.md).
