# src/features/profile-edit

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Редактирование личных данных в профиле.

**Текущее состояние:** вёрстка ProfileForm готова в P3-14 (PR #183): Input, Textarea, Select, локальные демонстрационные значения и кнопки. Города читаются из Redux. Форма пока не использует данные текущего пользователя, схему и сохранение; действия «Изменить пароль» / «Сохранить» подключает P7-06.

## Что внутри

- [`model/`](model/README.md) — типы, слайс, селекторы
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
