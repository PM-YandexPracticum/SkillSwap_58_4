# Модель редактора профиля

- `schema.ts` собирает `createProfileSchema(cityIds)` из общих правил. `createProfileEditSchema(cityIds, changePassword)` добавляет фото и условный новый пароль. Когда изменение пароля выключено, это поле исключается из результата; пустое «О себе» преобразуется в строку `''` для API.
- `profileValues.ts` подготавливает исходные значения и список изменений. DatePicker получает календарную дату `YYYY-MM-DD`; изменённая дата возвращается в API как ISO со временем. Сохранённый пароль в форму не попадает. Разрешены только поля профиля: связи навыков и лайки здесь не редактируются.
- `useProfileForm.ts` подключает Yup через resolver, управляет сменой пароля, обработкой фото и сохранением. Во время записи и чтения фото поля заблокированы. Общая ошибка записи не делает поля невалидными, поэтому сохранение можно повторить. Проверка занятого email остаётся в общем API.
- `schema.test.ts` и `profileValues.test.ts` проверяют ограничения, нормализацию и состав изменений. Пользовательские сценарии хука проверяются через `ProfilePersonal.test.tsx`.

Исходные значения обновляются только после успешной записи. Изменения других данных в store не стирают ввод. При размонтировании поздний ответ не меняет состояние редактора. При смене пользователя страница пересоздаёт форму по ключу пользователя и сессии.
