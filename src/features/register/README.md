# src/features/register

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Регистрация из трёх шагов (маршруты — в `pages/register`): формы и черновик в store. По ТЗ после завершения регистрации пользователь всегда попадает в каталог. Возврат на исходную страницу относится только к входу (P4-09).

**Текущее состояние:** StepCredentials свёрстан в P3-11 на CredentialsForm и react-hook-form. В P6-02 общая схема email и пароля подключена через yupResolver; ошибки видны после ухода из поля, кнопка заблокирована при неверных значениях или отправке. Работают проверка занятости email по загруженным пользователям, восстановление значений из черновика и переход на шаг 2 с сохранением данных и отметкой пройденного шага. OAuthButtons добавляет страница. StepProfile свёрстан в P3-12 на компонентах UI-кита, StepSkill свёрстан в P3-13 как колонка шага со слотами формы и окна. В P6-01 готовы действия черновика и прогресса, селекторы и сброс. Черновик живёт только в store, файлы в него не передаются. Окончательная проверка уникальности email перед записью согласуется с P4-06/P6-06; завершение регистрации подключает P6-06.
