# src/features/register/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `register` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `StepCredentials.tsx` — Шаг 1: «Продолжить с Google / Apple» (заглушки), Email, Пароль с подсказкой, «Далее», «Уже есть аккаунт? Войти». Email проверяется на формат и на то, что его ещё нет среди пользователей
- `StepProfile.tsx` — Шаг 2 «Расскажите немного о себе»: аватар (кружок с «+»), Имя, Дата рождения (DatePicker) + Пол (Select: Не указан / Мужской / Женский) в одну строку, Город (Select с поиском), «Категория навыка, которому хотите научиться» и «Подкатегория…» — CategorySubcategorySelect в режиме `multiple` (списки с чекбоксами). «Назад» / «Продолжить». «О себе» здесь нет — только в профиле
- `StepSkill.tsx` — Шаг 3 «Укажите, чем вы готовы поделиться». Слева SkillForm, справа иллюстрация и подпись «Так другие люди смогут увидеть ваши предложения и предложить вам обмен!». «Может научить» — ровно один навык. После «Продолжить» — SkillPreviewModal (1:1799): «Редактировать» возвращает к форме, «Готово» завершает регистрацию
