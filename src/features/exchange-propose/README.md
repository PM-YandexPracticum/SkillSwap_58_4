# src/features/exchange-propose

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

«Предложить обмен»: создаёт обмен и уведомление, показывает окно «Вы предложили обмен».

**Текущее состояние:** UI-компоненты получают состояние и обработчики пропсами, а сценарий P7-03
подключён в `SkillPage`: гость уходит на вход с возвратом, авторизованный пользователь сохраняет
обмен и уведомление через API P4-07, получает toast и окно подтверждения. Повторная попытка после
частичного сбоя не создаёт дубль.
## Что внутри

- [`model/`](model/README.md) — подготовка данных, сценарий сохранения и хук состояния
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда

Восстановление после частичного сбоя опирается на `Exchange.notificationPending`: повтор доступен и после перезагрузки. Хук `useProposeExchange` изолирует состояние интерфейса и отбрасывает поздние ответы после смены навыка или сессии. Общая функция склонения находится в `shared/lib/formatRecipientName`; кнопка, окно и Toast переиспользуются.
