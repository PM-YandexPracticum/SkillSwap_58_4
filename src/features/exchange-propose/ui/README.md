# src/features/exchange-propose/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `exchange-propose` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `ExchangeProposedModal.tsx` — Окно после «Предложить обмен»: иконка колокольчика, «Вы предложили обмен», «Теперь дождитесь подтверждения. Вам придёт уведомление», кнопка «Готово»
- `ProposeExchangeButton.tsx` — Кнопка «Предложить обмен» на странице навыка. Гость → регистрация (`/register/step-1`) с запоминанием страницы; после регистрации он вернётся сюда (1:3052). Вошедший: создаётся обмен и уведомление «Вы предложили обмен …», открывается ExchangeProposedModal (1:1977); после «Готово» кнопка становится обведённой неактивной «🕓 Обмен предложен», на колокольчике — красная точка (1:1919)
