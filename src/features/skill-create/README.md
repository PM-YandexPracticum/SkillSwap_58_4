# src/features/skill-create

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Навык, которому пользователь может научить: форма (шаг 3), превью «Ваше предложение», окно «Ваше предложение создано».

**Текущее состояние:** вёрстка P3-13 готова: `SkillForm` (форма шага 3 с зоной фото, «Назад» есть всегда), `SkillPreviewModal` («Ваше предложение» с галереей и мини-превью) и `OfferCreatedModal` («Ваше предложение создано»). Значения формы хранятся локально, проверок и сохранения нет; выбранные файлы превращаются в data URL через `fileToDataUrl`. До завершения обработки отправка недоступна, ошибки чтения видны под зоной фото. Галерея переиспользуется из `entities/skill/SkillGallery`. Валидацию, `skillSchema` и завершение регистрации подключат P6-05/P6-06.

## Что внутри

- [`model/`](model/README.md) — типы, слайс, селекторы
- [`ui/`](ui/README.md) — React-компоненты
