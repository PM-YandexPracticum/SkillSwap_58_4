# src/features/skill-create

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Навык, которому пользователь может научить: форма (шаг 3), превью «Ваше предложение», окно «Ваше предложение создано».

**Текущее состояние:** `SkillForm` и оба окна из P3-13 подключены к P6-05: обязательные поля проверяются через `skillSchema`, категория и подкатегория используют общую связь `single`, а файлы проверяются до обработки и принимаются в количестве 1–4. Значения и фото пока хранятся локально страницы; фото превращаются в data URL через `fileToDataUrl`, а отправка ждёт завершения обработки. Галерея переиспользуется из `entities/skill/SkillGallery`. Сохранение пользователя и навыка, создание сессии и завершение регистрации подключит P6-06.

## Что внутри

- [`model/`](model/README.md) — типы, слайс, селекторы
- [`ui/`](ui/README.md) — React-компоненты
- `index.ts` — публичный API — импортировать снаружи только отсюда
