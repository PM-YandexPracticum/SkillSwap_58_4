# src/features/skill-create/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill-create` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** форма и превью из P3-13 подключены к P6-05: значения проверяются через `skillSchema`, категории и подкатегории используют общую связь `single`, файлы проверяются до обработки и принимаются в количестве 1–4. В регистрации готовые data URL навыка восстанавливаются из общего черновика; завершение и запись сущностей выполняет `completeRegistration` в features/register (P6-06).

## Что внутри

- `OfferCreatedModal.tsx` — Окно после регистрации: галочка, «Ваше предложение создано», «Теперь вы можете предложить обмен», «Готово». `CatalogPage` открывает его по флагу `state.offerCreated` и удаляет флаг из текущей записи истории, чтобы окно не появлялось повторно. Отступы 62/60 px, иконка 100 px, окно 556 × 420 по актуальной Figma (согласованное уточнение прежних 80/60 px из задачи)
- `SkillForm.tsx` — Форма навыка, которому пользователь может научить (всегда ровно один): «Название навыка» — своё, например «Игра на барабанах»; «Категория навыка» и «Подкатегория навыка» — CategorySubcategorySelect в режиме `single`; «Описание»; фото — FileDropzone «Перетащите или выберите изображения навыка» (до 4, с превью и крестиком). «Назад» есть всегда, «Продолжить» отдаёт значения и фото в `onSubmit`. Выбранные файлы превращаются в data URL через `fileToDataUrl`, `onSubmit` получает их как `string[]`. `defaultImages` восстанавливает фото из черновика. Пока идёт обработка, выбор и отправка заблокированы, но удаление доступно; лимит не блокирует крестики. Читаются только файлы, помещающиеся в оставшийся лимит; ошибка обработки показана через FileDropzone, успешные фото сохраняются, повторный выбор доступен
- `SkillPreviewModal.tsx` — Превью созданного навыка на шаге 3: по центру «Ваше предложение» и «Пожалуйста, проверьте и подтвердите правильность данных»; слева название, «Категория / Подкатегория», описание и кнопки «Редактировать ✎» / «Готово»; справа общий `entities/skill/SkillGallery`: главное фото (Carousel) и колонка мини-превью (три штуки, на последней «+N»). Данные и адреса фото приходят пропсами. «Редактировать» (а также Esc и клик по фону) возвращает к форме, «Готово» вызывает `onConfirm`; во время записи действия заблокированы, ошибка показана внутри окна. После успешной записи навыка редактирование отключено, чтобы безопасный повтор использовал прежние id
- `SkillForm.module.css`, `SkillPreviewModal.module.css`, `OfferCreatedModal.module.css` — геометрия формы и окон по Figma
- `SkillForm.test.tsx`, `SkillPreviewModal.test.tsx`, `OfferCreatedModal.test.tsx` — поля и кнопки, выбор и удаление фото (до четырёх), данные в `onSubmit`, галерея и мини-превью, «Редактировать»/«Готово»/Esc
- `SkillForm.stories.tsx`, `SkillPreviewModal.stories.tsx`, `OfferCreatedModal.stories.tsx` — stories по макетам 1:1761, 1:1799, 1:2950
