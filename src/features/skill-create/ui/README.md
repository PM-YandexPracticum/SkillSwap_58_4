# src/features/skill-create/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill-create` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** вёрстка P3-13 готова: `SkillForm`, `SkillPreviewModal` и `OfferCreatedModal`. Значения формы хранятся локально, проверок и сохранения нет. Валидацию, `skillSchema` и завершение регистрации подключат P6-05/P6-06.

## Что внутри

- `OfferCreatedModal.tsx` — Окно после регистрации: галочка, «Ваше предложение создано», «Теперь вы можете предложить обмен», «Готово». Показывается в каталоге, куда пользователь попадает после регистрации (флаг `state.offerCreated`, P6-06)
- `SkillForm.tsx` — Форма навыка, которому пользователь может научить (всегда ровно один): «Название навыка» — своё, например «Игра на барабанах»; «Категория навыка» и «Подкатегория навыка» — CategorySubcategorySelect в режиме `single`; «Описание»; фото — FileDropzone «Перетащите или выберите изображения навыка» (до 4, с превью и крестиком). «Назад» есть всегда, «Продолжить» отдаёт значения и фото в `onSubmit`. Выбранные файлы превращаются в data URL через `fileToDataUrl`, `onSubmit` получает их как `string[]`
- `SkillPreviewModal.tsx` — Превью созданного навыка на шаге 3: по центру «Ваше предложение» и «Пожалуйста, проверьте и подтвердите правильность данных»; слева название, «Категория / Подкатегория», описание и кнопки «Редактировать ✎» / «Готово»; справа галерея: главное фото (Carousel) и колонка мини-превью (три штуки, на последней «+N»). Данные и адреса фото приходят пропсами. «Редактировать» (а также Esc и клик по фону) возвращает к форме, «Готово» завершает регистрацию
- `SkillForm.module.css`, `SkillPreviewModal.module.css`, `OfferCreatedModal.module.css` — геометрия формы и окон по Figma
- `SkillForm.test.tsx`, `SkillPreviewModal.test.tsx`, `OfferCreatedModal.test.tsx` — поля и кнопки, выбор и удаление фото (до четырёх), данные в `onSubmit`, галерея и мини-превью, «Редактировать»/«Готово»/Esc
- `SkillForm.stories.tsx`, `SkillPreviewModal.stories.tsx`, `OfferCreatedModal.stories.tsx` — stories по макетам 1:1761, 1:1799, 1:2950
