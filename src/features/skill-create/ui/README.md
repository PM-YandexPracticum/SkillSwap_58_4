# src/features/skill-create/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `skill-create` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `OfferCreatedModal.tsx` — Окно после регистрации: «Ваше предложение создано» — показывается в каталоге, куда пользователь попадает после «Готово»
- `SkillForm.tsx` — Форма навыка, которому пользователь может научить (всегда ровно один): «Название навыка» — своё, например «Игра на барабанах»; «Категория навыка» и «Подкатегория навыка» — CategorySubcategorySelect в режиме `single`; «Описание»; фото — FileDropzone «Перетащите или выберите изображения навыка» (1–4). «Назад» / «Продолжить»
- `SkillPreviewModal.tsx` — Превью созданного навыка на шаге 3: «Ваше предложение», «Пожалуйста, проверьте и подтвердите правильность данных», название, «Категория / Подкатегория», описание, галерея фото (Carousel). «Редактировать ✎» закрывает окно и возвращает к форме, «Готово» завершает регистрацию
