# src/widgets/notifications-panel

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Окно колокольчика: «Вы предложили обмен …» → «Перейти», «Прочитать все», «Очистить». Уведомления номинальные: обмены не подтверждаются, просмотренные не кликаются.
Макет: 1:2190 (окно), 1:2148 (экран с открытой панелью), 1:2239 (после «Прочитать все»), 1:2328 (уведомления в действии).

## Границы ответственности

`MainLayout` передаёт панель в слот `Header` и связывает действия с Redux и навигацией.
Шапка показывает колокольчик и точку из `selectHasUnread`, но не загружает данные.
Единственный загрузчик `useNotifications` работает и при закрытом окне, отдельно от `DataProvider`.

Ошибка загрузки показывается с кнопкой «Повторить». Ошибки прочтения и очистки
не скрывают список, активная операция блокирует повторный клик. Прочитанные записи
не кликаются. При переходе на страницу навыка окно закрывается.
