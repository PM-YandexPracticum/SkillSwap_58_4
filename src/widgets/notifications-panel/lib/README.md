# src/widgets/notifications-panel/lib

Чистые функции без React и Redux. Панель не склоняет имена и не ищет навыки самостоятельно.

- `buildNotificationsWithNames.ts` — добавляет имя адресата в дательном падеже к уже отобранным селектором уведомлениям. Использует `formatRecipientName` из `shared`. Если адресат не найден, запись остаётся с подписью «пользователю»: список не расходится с точкой непрочитанных.
- `findSkillId.ts` — находит навык по `exchangeId`. Если обмен ещё не загружен, `MainLayout` использует `teachSkillId` адресата; перед переходом проверяет владельца навыка. Недоступный навык объясняется сообщением, перехода на чужую страницу нет.
- `*.test.ts` — склонение имён, отсутствующий адресат, пустые данные и поиск обмена.
