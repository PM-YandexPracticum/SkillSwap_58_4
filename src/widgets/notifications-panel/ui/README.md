# src/widgets/notifications-panel/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `notifications-panel` — React-компоненты. Панель «глупая»: данные и обработчики получает пропсами. Подключение к шапке и store — `MainLayout` (P7-05): он передаёт панель в слот `notifications` компонента `Header` и передаёт обработчики `onMarkAllRead`, `onClear`, `onGo`. `onGo` получает **id уведомления**; адрес страницы навыка обработчик ищет через `findSkillId` из `../lib`.

## Что внутри

- `NotificationsPanel.tsx` — dumb-окно колокольчика: «Новые уведомления» + «Прочитать все», ниже «Просмотренные» + «Очистить». Статусы загрузки и ошибки получает props. Новые имеют «Перейти», просмотренные не кликаются; пусто показывается только после успешной загрузки.
- `NotificationsPanel.module.css` — стили панели: ширина 556 (Figma: 1:2190), секции и заголовки (Figma: 1:2148)
- `NotificationsPanel.stories.tsx` — истории Storybook: новые / просмотренные / смешанные / пусто (Figma: 1:2190, 1:2148)
- `NotificationsPanel.test.tsx` — тесты панели: секции по `isRead`, пустое состояние, обработчики кнопок

При четырёх уведомлениях (два новых и два просмотренных) панель имеет размер 556 × 616 px по Figma 1:2190. Рамка нарисована внутри через `box-shadow`, чтобы не уменьшать ширину контента 436 px; у кнопок заголовков локально убраны вертикальные отступы общего Button.

После успешной загрузки пустой список показывает общий `EmptyState` с `compact` (P8-03): прежний текст «Уведомлений пока нет», нейтральный цвет и вертикальные отступы 40 px, без кнопки перехода в каталог. Этот вариант не нарисован отдельным фреймом; оформление сохраняет прежнее состояние панели. Загрузка и ошибка с кнопкой повтора по-прежнему обрабатываются самой панелью по входным props.
