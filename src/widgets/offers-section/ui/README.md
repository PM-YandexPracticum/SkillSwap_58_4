# src/widgets/offers-section/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `offers-section` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `OffersSection.tsx` — Секция каталога: заголовок, кнопка «Смотреть все →» и сетка OfferCard строго по 3 в ряд. Два режима: - `expandable` — «Популярное» и «Новое»: 3 карточки; «Смотреть все» раскрывает до 9 (ещё два ряда), секции ниже сдвигаются; повторный клик сворачивает обратно; - `infinite` — «Рекомендуем», результаты фильтров, избранное: лента с догрузкой по 6 при прокрутке (useInfiniteScroll). Карточки между секциями могут повторяться — это нормально
