# src/widgets/offers-section

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Секция каталога: заголовок, кнопка «Смотреть все» и сетка строго по три. Раскрытие 3 ⇄ 9 реализовано в P3-08. В P5-06 режим ленты получил спиннер догрузки и маркер конца ленты; страницу и порцию передаёт контейнер через `useInfiniteScroll`, а виджет показывает только переданные элементы.

## Что внутри

- [`ui/`](ui/README.md) — React-компонент, тесты и stories
- `index.ts` — публичный API — импортировать снаружи только отсюда
