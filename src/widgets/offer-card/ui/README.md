# src/widgets/offer-card/ui

UI карточки предложения для каталога. Виджет собирает данные из store и передаёт их в `UserCard`; соседние виджеты не импортирует.

## Что внутри

- `OfferCard.tsx` — карточка пользователя с сердечком, счётчиком лайков и ссылкой «Подробнее» или статусом «Обмен предложен».
- `OfferCard.module.css` — оформление ссылки-кнопки.
- `OfferCard.test.tsx` — проверяет сборку данных, переход, направление обмена, смену сессии, сохранение и повторную загрузку через thunk, ошибку записи и клавиатуру.
- `OfferCard.stories.tsx` — состояния по макету: гость, вошедший без предложения, обмен предложен, без фото, без лайков, длинное имя.

## Решения P3-08

- Figma: [карточка Ивана, 1:2877](https://www.figma.com/design/40gXmyAoxwwnb9kBxI5B8y/SkillSwap-Red.1-?node-id=1-2877).
- Счётчик добавлен по ТЗ: в макете только сердечко. Число стоит слева от иконки, чтобы длинное имя не пересекалось с ним; положение иконки и размеры карточки сохранены.
- «Подробнее» — `Link`, поскольку это переход. Общий `Button` пока не поддерживает ссылку; вложенной кнопки внутри ссылки нет.
- Пока справочники не загружены, вместо `undefined` показываются «Город не указан» / «Навык не найден». Неизвестные подкатегории пропускаются.
- Пример композиции реальных карточек и секций — story `app/CatalogSections`.

## Статус P7-04

`WithProposedExchange` показывает исходящее предложение текущего пользователя; `Guest` проверяет, что запись обмена в store не заменяет ссылку без сессии; `Authorized` показывает вошедшего без предложения. Бейдж статичный, декоративная иконка скрыта от скринридера. Загрузка обменов в страницу пока не подключена; контракт интеграции описан в [README виджета](../README.md#статус-обмена-p7-04).
