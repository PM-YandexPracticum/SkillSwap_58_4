# src/widgets/filters-panel/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `filters-panel` — React-компоненты. Получают данные пропсами или из store через селекторы.

**Текущее состояние:** реализована вёрстка P3-07, а подключение фильтров — P5-02 (PR #175). Панель читает категории и города через `selectCategories` / `selectCities` и передаёт их компонентам `catalog-filter`. Загрузкой справочников и обработкой ошибок управляет страница. Вывод результатов и сортировка остаются в P5-05.

## Что внутри

- `FiltersPanel.tsx` — Левая колонка «Фильтры (N) / Сбросить»: ModeFilter, SkillsFilter, GenderFilter, CityFilter

## Контракт

- `className` — внешний CSS-класс; `filtersCount` — внешний счётчик для «Фильтры (N)», по умолчанию 0 без числа в заголовке; `onReset` — необязательный обработчик кнопки сброса.
- P3-07 отвечает за вёрстку и доступность панели. В P5-02 галочки и радиовыбор меняют `catalogFilter` в store, а контейнер передаёт счётчик и общий сброс. Без `onReset` сброс остаётся номинальным; фильтрация списка и результаты относятся к P5-05.
- Панель — подписанный `aside`, ширина по макету 324 px, внутренний отступ 20 px, радиус 12 px. Между блоками 32 px, между шапкой и режимом 40 px; размеры и шрифты опираются на токены проекта.
- Если справочники пусты, группы остаются видимыми без элементов. Дополнительный экран ошибки, повторная загрузка и подключение к страницам в P3-07 не добавляются.
- `FiltersPanel.stories.tsx` — справочники через loaders и Provider только с двумя нужными редьюсерами; обычное, пустое, со счётчиком и частично выбранное состояния. Данные не копируются из JSON в код.
- `FiltersPanel.test.tsx` — селекторы, появление данных, внешний счётчик/сброс, независимые экземпляры и отсутствие бизнес-действий Redux. Используется общий `renderWithProviders`.
