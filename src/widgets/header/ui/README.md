# src/widgets/header/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `header` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `Header.tsx` — шапка сайта в двух видах (проп `isAuth`). Гость: Logo, «О проекте», «Все навыки ▾», SearchInput, иконка темы (пока без действия — фаза 9), «Войти», «Зарегистрироваться». Вошедший: вместо кнопок — колокольчик с красной точкой непрочитанных (`hasUnread`), сердечко → `/favorites` (на странице избранного подсвечено), имя + аватар → меню «Личный кабинет» / «Выйти». Меню «Все навыки» и окно уведомлений — соседние виджеты, поэтому приходят слотами `categoriesMenu` и `notifications` от `MainLayout`; одновременно открыто одно меню. Вид по сессии выберет P5-09
- `Header.module.css` — стили шапки
- `Header.stories.tsx` — гость, вошедший (с точкой и без), открытые меню; в слотах заглушки, Redux Provider содержит только слайс поиска
- `Header.test.tsx` — тесты обоих видов, меню, ссылок, клавиатуры и поиска в store через общий `renderWithProviders`

В P3-06 `MainLayout` подключает готовый `CategoriesMenu`. Панель ограничена высотой окна;
область прокрутки доступна по Tab, Escape закрывает её и возвращает фокус на «Все навыки».
Интеграция меню, клавиатура и переход из Footer на `/skills` проверяются в `MainLayout.test.tsx`.
