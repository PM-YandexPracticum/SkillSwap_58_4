# src/widgets/header/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `header` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `Header.tsx` — Шапка сайта. Гость: Logo, «О проекте», «Все навыки ▾» (CategoriesMenu), SearchInput, иконка темы (необязательная фича, фаза 9), «Войти», «Зарегистрироваться». Вошедший: вместо кнопок — колокольчик с точкой непрочитанных (NotificationsPanel), сердечко → `/favorites` (на странице избранного сердечко подсвечено), имя + аватар → меню «Личный кабинет» / «Выйти»
