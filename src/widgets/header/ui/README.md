# src/widgets/header/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `header` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `Header.tsx` — выбирает вид через `selectIsAuth`, имя и аватар читает из `selectCurrentUser`. Точку непрочитанных определяет `selectHasUnread`; до интеграции P7-05 Header загружает уведомления из состояния idle. Панель, ошибку и повтор подключает P7-05 через `MainLayout`. Меню пользователя содержит ссылку на личный кабинет и `LogoutButton`.
- `Header.module.css` — стили шапки; длинное имя ограничено по ширине и обрезается многоточием, полный текст доступен по наведению и скринридеру.
- `Header.stories.tsx` — Guest, Authorized, AuthorizedWithUnread, MenuOpen, LongName и примеры слотов. Вид задаётся состоянием Redux.
- `Header.test.tsx` — сессия, обновление имени и аватара, собственные уведомления, ссылки и меню с клавиатуры.

В P3-06 `MainLayout` подключает готовый `CategoriesMenu`. Панель ограничена высотой окна;
область прокрутки доступна по Tab, Escape закрывает её и возвращает фокус на «Все навыки».
Интеграция меню, клавиатура и переход из Footer на `/skills` проверяются в `MainLayout.test.tsx`.

До интеграции P7-05 Header загружает уведомления при входе пользователя, поэтому точка восстанавливается после перезагрузки до открытия панели. P7-05 перенесёт этот запуск в единый контур панели вместе с ошибкой и повтором; второй загрузчик не добавляем.
