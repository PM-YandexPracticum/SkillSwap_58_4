# src/widgets/footer/ui

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Сегмент **ui** слайса `footer` — React-компоненты. Получают данные пропсами или из store через селекторы.

## Что внутри

- `Footer.tsx` — Подвал: логотип, ссылки, «SkillSwap — 2025». Рабочие: «О проекте» → `/about` (страница команды), «Все навыки» → `/skills` (отдельная страница). Заглушки: «Контакты», «Блог», «Политика конфиденциальности», «Пользовательское соглашение» — выглядят как ссылки, но ни на что не реагируют
