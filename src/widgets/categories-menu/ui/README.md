# src/widgets/categories-menu/ui

## Что внутри

- `CategoriesList.tsx` — шесть категорий и все подкатегории из Redux. Две независимые колонки по Figma: бизнес, языки и дом слева; творчество, образование и здоровье справа. Внутри колонок сохраняется порядок справочника; дополнительные категории не теряются.
- `CategoriesList.module.css` — колонки, заголовки Jost, подпункты Roboto и состояния обратной связи на токенах проекта.
- `CategoriesList.test.tsx` — содержание, готовый справочник без повторного запроса, ошибка общего загрузчика без отдельного retry, пустое состояние, дополнительная категория без подкатегорий, обновление store и два списка.
- `CategoriesMenu.tsx` — панель 1136 px с отступом 60 px, без собственного Dropdown и кнопки.
- `CategoriesMenu.module.css` — размеры, белый фон и скругление панели.
- `CategoriesMenu.stories.tsx` — Default, Loading, Error, Empty. Реальный справочник загружается через `loadSeed`; отдельный store на каждую историю.

Макет: [Все навыки, 1:3165](https://www.figma.com/design/40gXmyAoxwwnb9kBxI5B8y/SkillSwap-Red.1-?node-id=1-3165).
Loading, ошибка и пустой справочник в макете не нарисованы: список использует Loader и текстовые сообщения. Повтор загрузки выполняется на общей странице /500 через DataProvider.
Позиционирование, ограничение высоты и фокусируемую область прокрутки предоставляет Header/Dropdown.
Пункты списка не входят в Tab-порядок; область прокрутки меню доступна одной остановкой Tab.
