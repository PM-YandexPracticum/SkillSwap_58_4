# src/widgets/categories-menu

Статичный справочник «Все навыки» для меню Header и страницы `/skills` (P3-06).

**Текущее состояние:** P3-06 завершена (PR #165). CategoriesList и CategoriesMenu реализованы, подключены в MainLayout и на `/skills`; загрузка, ошибка и пустой список покрыты тестами и stories. Стартовую загрузку и повтор при ошибке выполняет DataProvider (P4-04).

## Что внутри

- [`ui/`](ui/README.md) — общий `CategoriesList`, панель `CategoriesMenu`, стили, тесты и stories.
- `index.ts` — публичный API компонентов и типов их пропсов.

`CategoriesMenu` — только содержимое слота. Кнопкой, Dropdown, открытием и закрытием управляет Header;
MainLayout соединяет два виджета без нарушения FSD. Страница `/skills` использует ту же панель.
Пункты справочника — текст, без фильтрации и переходов.

Данные читаются из Redux через селекторы `entities/category`. CategoriesList не отправляет запросы: при `idle` / `loading` показывает Loader, при `failed` — сообщение, при пустом справочнике — пустое состояние. В приложении загрузку и восстановление после ошибки координирует DataProvider; в тестах и stories состояние задаётся через store.
