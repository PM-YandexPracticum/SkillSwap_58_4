# src/widgets/categories-menu

Статичный справочник «Все навыки» для меню Header и страницы `/skills` (P3-06).

## Что внутри

- [`ui/`](ui/README.md) — общий `CategoriesList`, панель `CategoriesMenu`, стили, тесты и stories.
- `index.ts` — публичный API компонентов и типов их пропсов.

`CategoriesMenu` — только содержимое слота. Кнопкой, Dropdown, открытием и закрытием управляет Header;
MainLayout соединяет два виджета без нарушения FSD. Страница `/skills` использует ту же панель.
Пункты справочника — текст, без фильтрации и переходов.

Данные читаются из Redux через селекторы `entities/category`. До общей загрузки P4-04 список вызывает
`fetchCategories` в состоянии `idle`. Thunk пропускает запрос при `loading` / `succeeded`, в том числе
при одновременном открытии двух списков и в StrictMode. После ошибки доступен ручной повтор.
