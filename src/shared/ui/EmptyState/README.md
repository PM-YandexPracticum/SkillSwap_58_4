# src/shared/ui/EmptyState

## Зачем эта папка

Общее отображение пустого списка для каталога, избранного и уведомлений (P8-03).
`EmptyState` получает сообщение (`title`), необязательные описание, декоративную иконку
и действие. Кнопка — общий `Button` с вариантом `secondary`.

Компонент не читает store, не загружает данные и не выбирает причину пустого списка.
Родитель показывает его после успешной загрузки и передаёт нужное действие.
Сообщение объявляется через `role="status"`; заголовок раздела остаётся снаружи.

## Использование

- `CatalogView` различает отсутствие предложений и отсутствие совпадений.
  Полный сброс поиска и фильтров приходит из `CatalogPage` через `results.onReset`.
  Сброс в боковой панели по-прежнему очищает только фильтры.
- `FavoritesPage` сохраняет заголовок «Избранное» и белый блок высотой от 368 px.
  При пустом избранном действие ведёт в каталог; при отсутствии совпадений сбрасывает поиск и фильтры.
  Фон и размер задаются через `className`, без повторения внутренней раскладки компонента.
- `NotificationsPanel` передаёт `compact` и текст «Уведомлений пока нет» без кнопки.
  Отступы 40 px по вертикали и нейтральный цвет сохранены из прежней панели.
  Во время загрузки и ошибки панель показывает свои Loader и сообщение с повтором.

Стартовая загрузка общих данных и переход на /500 принадлежат `DataProvider`.
Догрузка карточек остаётся в `OffersSection` и `useInfiniteScroll`.

## Что внутри

- `EmptyState.tsx` — сообщение, описание, иконка и действие без бизнес-логики.
- `EmptyState.module.css` — общая раскладка и компактный режим на токенах проекта.
- `EmptyState.test.tsx` — необязательные элементы, доступное сообщение и действие мышью/клавиатурой.
- `EmptyState.stories.tsx` — пустая база, поиск, избранное, отфильтрованное избранное, уведомления и иконка.
- `index.ts` — публичный экспорт компонента и его пропсов.
