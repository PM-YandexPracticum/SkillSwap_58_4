# Field

Общая обвязка Input и Textarea: уникальный id, подпись, ошибка и связь через aria-describedby.
Дочерняя render-функция получает только атрибуты доступности; тип поля и ref остаются у Input/Textarea.
`Field.module.css` хранит общие стили полей. Input и Textarea подключают его напрямую,
а отличия многострочного поля задаются в `Textarea.module.css`.
`Field.test.tsx` проверяет подпись, заданный id, связь подсказки с ошибкой и снятие ошибки.
Интеграционные тесты Input и Textarea дополнительно проверяют работу конкретных полей и ref.
`Field.stories.tsx` показывает обычное состояние, внешнюю подсказку и ошибку.
