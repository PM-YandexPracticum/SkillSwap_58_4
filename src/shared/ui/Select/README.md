# src/shared/ui/Select

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **Select**. Выпадающий список с одним выбором: «Пол» (Не указан / Мужской / Женский), «Город», «Категория», «Подкатегория».

## Что внутри

- `Select.stories.tsx` — Stories состояний Select
- `Select.module.css` — единая раскрывающаяся рамка и состояния на токенах проекта
- `Select.test.tsx` — выбор мышью и клавиатурой, поиск, очистка, disabled, ошибки и обновление вариантов
- `Select.tsx` — Выпадающий список с одним выбором: «Пол» (Не указан / Мужской / Женский), «Город», «Категория», «Подкатегория» и управлением клавиатурой. `value: null` соответствует варианту «Не указан»; для выбора этого варианта передайте option с `value: null`.
- `index.ts` — публичный API — импортировать снаружи только отсюда

Поддерживаются состояния ошибки и disabled, закрытие по клику вне и Esc. Для поиска передайте `searchable`: поле ввода фильтрует варианты, а кнопка справа очищает поисковый текст и выбранное значение.

Ширину задаёт родитель: поле занимает 100% контейнера (в макете «Пол» — 208 px, «Город» — 436 px). Раскрытый список накладывается на поля ниже и не меняет высоту формы. Данные и связь категории с подкатегорией остаются у потребителя.

Enter, пробел (обычный Select) и стрелки открывают список; стрелки меняют активный пункт с прокруткой, Enter выбирает. Esc закрывает список и возвращает фокус на поле. При уходе фокуса компонент закрывается; Tab сохраняет обычную навигацию, в поисковом режиме кнопка очистки доступна с клавиатуры. Disabled запрещает открытие, выбор и очистку. При замене вариантов активный пункт определяется по значению, поэтому ссылка на удалённый пункт не остаётся.

Макет: «Регистрация 2 шаг», [«Пол» (1:1585)](https://www.figma.com/design/40gXmyAoxwwnb9kBxI5B8y/SkillSwap-Red.1-?node-id=1-1585), [поиск «Город» (1:1629)](https://www.figma.com/design/40gXmyAoxwwnb9kBxI5B8y/SkillSwap-Red.1-?node-id=1-1629).

Для форм доступны `onBlur` (уход фокуса за пределы всего поля со списком) и `ref` на основное поле. Переход к кнопке очистки или чекбоксам внутри списка не вызывает внешний `onBlur`.
