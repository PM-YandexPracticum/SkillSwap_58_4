# src/shared/ui/Carousel

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **Carousel**. Обёртка над библиотекой карусели (выбирает и ставит тимлид, например embla-carousel-react или swiper): стрелки, листание, стили под макет. Своя логика листания не пишется — наставник просит библиотеку. Где используется: фото в превью навыка (шаг 3 регистрации), галерея и «Похожие предложения» на странице навыка.

## Что внутри

- `Carousel.stories.tsx` — Stories компонента Carousel — ЗАГЛУШКА. Пакеты Storybook ставит задача P1-11; после неё добавить типы: `const meta: Meta<typeof Carousel>` и `export const Default: StoryObj<typeof meta>`
- `Carousel.tsx` — Обёртка над библиотекой карусели (выбирает и ставит тимлид, например embla-carousel-react или swiper): стрелки, листание, стили под макет. Своя логика листания не пишется — наставник просит библиотеку. Где используется: фото в превью навыка (шаг 3 регистрации), галерея и «Похожие предложения» на странице навыка
- `index.ts` — публичный API — импортировать снаружи только отсюда
