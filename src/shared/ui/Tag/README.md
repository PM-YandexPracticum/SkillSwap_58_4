# src/shared/ui/Tag

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **Tag**. Цветной чип: навык на карточке («Игра на барабанах», «+2») или «плашка» с крестиком — выбранный фильтр над результатами и выбранное «Хочу научиться» на шаге 2 регистрации (тот же компонент). Вариант `filter` повторяет крупный вид плашки каталога. Цвет зависит от категории.

## Что внутри

- `Tag.stories.tsx` — stories: все цвета категорий, плашка с крестиком
- `Tag.tsx` — Цветной чип: навык на карточке («Игра на барабанах», «+2») или «плашка» с крестиком — выбранный фильтр над результатами и выбранное «Хочу научиться» на шаге 2 регистрации (тот же компонент). Вариант `filter` повторяет крупный вид плашки каталога. Цвет зависит от категории. В узком месте длинное название обрезается многоточием, а при наведении мышью видна подсказка с полным названием
- `Tag.test.tsx` — тесты: чип и плашка с крестиком, `isTagColor`, подсказка у обрезанного названия
- `index.ts` — публичный API — импортировать снаружи только отсюда: `Tag`, тип `TagColor` и `isTagColor(categoryId)` — проверить, что у категории из данных есть цвет чипа
