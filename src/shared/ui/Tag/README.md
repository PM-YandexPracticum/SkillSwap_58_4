# src/shared/ui/Tag

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **Tag**. Цветной чип: навык на карточке («Игра на барабанах», «+2») или «плашка» с крестиком — выбранный фильтр над результатами и выбранное «Хочу научиться» на шаге 2 регистрации (тот же компонент). Цвет зависит от категории.

## Что внутри

- `Tag.stories.tsx` — Stories компонента Tag — ЗАГЛУШКА. Пакеты Storybook ставит задача P1-11; после неё добавить типы: `const meta: Meta<typeof Tag>` и `export const Default: StoryObj<typeof meta>`
- `Tag.tsx` — Цветной чип: навык на карточке («Игра на барабанах», «+2») или «плашка» с крестиком — выбранный фильтр над результатами и выбранное «Хочу научиться» на шаге 2 регистрации (тот же компонент). Цвет зависит от категории
- `index.ts` — публичный API — импортировать снаружи только отсюда
