# src/shared/ui/Modal

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **Modal**. Модальное окно с затемнением фона. Закрывается по Esc и клику на фон, фокус остаётся внутри окна и после закрытия возвращается туда, откуда окно открыли. Рендер через portal в `document.body`. Содержимое передаётся через `children` — сам `Modal` про заголовки, тексты и кнопки ничего не знает.

- Пропсы: `isOpen`, `onClose`, `children` и обязательный `ariaLabel` — название окна для скринридера («Вы предложили обмен»).
- Внутренние отступы задаёт содержимое: в макете они у окон разные — 80/60 px у «Вы предложили обмен» и «Ваше предложение создано», 40 px у превью навыка.
- При фокусе с клавиатуры видна рамка окна; слой `--z-modal` располагается выше поповеров.
- Окно по центру экрана; высокое окно прокручивается вместе с фоном, страница под ним не прокручивается.
- `onClose` можно передавать прямо в разметке (`onClose={() => setIsOpen(false)}`) — перерисовка родителя фокус не сбивает.
- Клик по фону закрывает окно, только если и нажатие, и отпускание мыши были на фоне — выделение текста в окне его не закроет.

## Что внутри

- `Modal.module.css` — стили: `.overlay` (затемнение и размытие как в макете, прокрутка высокого окна), `.window` (белое окно по центру, скругление)
- `Modal.stories.tsx` — stories: `Default` с заголовком, текстом и кнопкой; `LongContent` — высокое окно, как превью навыка
- `Modal.test.tsx` — тесты: подпись, Esc и возврат фокуса, клик по фону и по окну, выделение текста, ввод в поле внутри окна, Tab по кругу, блокировка прокрутки страницы
- `Modal.tsx` — модальное окно: портал, Esc, клик по фону, focus trap, возврат фокуса, `role="dialog"`, `aria-modal`, `ariaLabel`, блокировка прокрутки страницы
- `index.ts` — публичный API — импортировать снаружи только отсюда
