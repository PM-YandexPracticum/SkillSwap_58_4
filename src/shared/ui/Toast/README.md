# src/shared/ui/Toast

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Универсальное уведомление: иконка, переданный текст и кнопка закрытия. В сценарии обмена текст —
«Вы предложили обмен Ивану» (ТЗ наставника). Внешний вид — Figma 1:2148 (1:1975, 1:1976).

## Что внутри

- `Toast.tsx` — принимает `message` и `onClose`; сам не управляет временем жизни.
  Высота зависит от текста: 72 px для одной строки, 96 px для двух.
  Кнопка «Закрыть уведомление» доступна через Tab, Enter и пробел. Иконки скрыты от скринридера
- `Toast.module.css` — CSS Modules на токенах проекта: ширина 340 px, отступы 24 px, Jost Medium 20/24, фон `--color-accent-soft`, радиус 12 px; длинный текст переносится
- `Toast.stories.tsx` — `Default` с рабочим закрытием и повторным показом, `LongMessage` с длинным текстом
- `Toast.test.tsx` — отображение текста и вызов обработчика закрытия
- `index.ts` — публичный API

Для показа из приложения используйте `useToast` из `@/shared/lib/toast`. Подключённый в `App`
провайдер отвечает за позиционирование, объявление скринридером и таймер 4 секунды.
Настоящий жизненный цикл демонстрирует story `app/providers/ToastProvider/Interactive`:
она лежит в `app`, чтобы `shared` не импортировал верхний слой.
