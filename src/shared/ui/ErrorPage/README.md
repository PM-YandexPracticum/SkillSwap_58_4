# src/shared/ui/ErrorPage

Общая рамка, иллюстрация, текст и действия страниц 404/500 (P3-16). Компонент не зависит от маршрутизатора и не выполняет переходов.

## Что внутри

- `ErrorPage.tsx` — общая рамка, изображение, `<h1>`, описание и слот действий; экспортирует `ErrorPageProps`.
- `ErrorActions.tsx` — две кнопки страниц ошибок; переход передаётся через `onHome`, сообщение остаётся заглушкой по ТЗ.
- `ErrorPage.module.css` — размеры, типографика и отступы на токенах проекта.
- `index.ts` — публичные экспорты `ErrorPage`, `ErrorActions` и их типов.

## Контракт

`errorImage`, `title`, `description` — обязательные строки; `errorType` — `'404' | '500'`, определяет alt иллюстрации. Необязательный `actions` добавляется в общую область действий. Компонент не знает о маршрутах: страницы [not-found](../../../pages/not-found/README.md) и [server-error](../../../pages/server-error/README.md) передают ему навигацию через `ErrorActions`. Их тесты и stories проверяют итоговый экран.

Показ 500 при ошибке рендера остаётся в P8-01; этот компонент сам ошибки не перехватывает.
