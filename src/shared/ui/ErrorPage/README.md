# src/shared/ui/ErrorPage

Общая иллюстрация и текст страниц 404/500 (P3-16). Компонент не зависит от маршрутизатора и не выполняет переходов.

## Что внутри

- `ErrorPage.tsx` — изображение, `<h1>` и описание; экспортирует `ErrorPageProps`.
- `ErrorPage.module.css` — размеры, типографика и отступы на токенах проекта.
- `index.ts` — публичные экспорты `ErrorPage` и `ErrorPageProps`.

## Контракт

`errorImage`, `title`, `description` — обязательные строки; `errorType` — `'404' | '500'`, определяет alt иллюстрации. Компонент не создаёт `<main>` и кнопки: страницы [not-found](../../../pages/not-found/README.md) и [server-error](../../../pages/server-error/README.md) собирают рамку и действия из общих компонентов. Их тесты и stories проверяют итоговый экран.

Показ 500 при ошибке рендера остаётся в P8-01; этот компонент сам ошибки не перехватывает.
