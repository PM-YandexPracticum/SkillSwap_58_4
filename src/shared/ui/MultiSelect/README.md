# MultiSelect

Управляемый выпадающий список с чекбоксами. Состояние выбора передаётся через `value`, изменения через `onChange`. В закрытом поле видно первое выбранное название и счётчик остальных `+N`.

Enter и пробел открывают поле. Стрелки перемещают фокус по пунктам, пробел и Enter переключают чекбокс. Escape закрывает список и возвращает фокус на поле. Клик снаружи и переход фокуса за пределы списка также закрывают его.

Если активный пункт удалён из `options`, фокус возвращается на поле. При пустом списке или `disabled` панель закрывается и сама не открывается после появления вариантов или включения компонента. Изменение `value` снаружи сразу обновляет отметки и подпись; компонент сам не очищает выбранные значения при смене вариантов — это решает родитель.

## Что внутри

- `MultiSelect.tsx` — компонент и публичные типы пропсов.
- `MultiSelect.module.css` — оформление списка с чекбоксами; общий вид поля переиспользуется из Select.
- `MultiSelect.test.tsx` — выбор, клавиатура, внешние обновления и фокус.
- `MultiSelect.stories.tsx` — состояния компонента и ссылки на макет.
- `index.ts` — публичный API.

## Использование

```tsx
import { MultiSelect } from '@/shared/ui/MultiSelect'

<MultiSelect
  label="Категории"
  placeholder="Выберите категорию"
  options={options}
  value={selectedIds}
  onChange={setSelectedIds}
/>
```
