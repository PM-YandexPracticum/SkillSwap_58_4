# src/shared/ui/DatePicker

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

UI-компонент **DatePicker**. Поле «Дата рождения» с иконкой календаря — обёртка над библиотекой (`react-datepicker` 9 уже установлен в P1-10). Календарь сами не верстаем: подключаем библиотеку, включаем выбор месяца и года, русскую локаль, неделю с понедельника, кнопки «Отменить» / «Выбрать» и стилизуем под макет. Наружу отдаём ISO-строку. Совместим с react-hook-form через `Controller`.
