# Тема интерфейса

`initializeTheme` применяет сохранённую тему до первого React-рендера. Без сохранённого
выбора используется `prefers-color-scheme`. Значение `skillswap_theme` — `light` или `dark`;
постороннее значение игнорируется, недоступное хранилище не мешает переключению.

`useTheme` подписывается на общий источник через `useSyncExternalStore`. Пока есть подписчики,
работает одна пара слушателей: системной темы и `storage` других вкладок. Последняя отписка
снимает оба. Ручной выбор имеет приоритет до удаления ключа; выход из аккаунта тему не сбрасывает.

Тема задаёт `data-theme` и `color-scheme` у `html`. Палитры находятся в `app/styles/global.css`,
а кнопка из `features/theme-toggle` меняет только выбор. Возможность включается флагом
`FEATURE_FLAGS.DARK_THEME`; при выключенном флаге применяется только светлая тема и слушатели
системной темы не подключаются. Никаких бизнес-данных этот модуль не хранит.
