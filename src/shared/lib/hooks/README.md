# src/shared/lib/hooks

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Универсальные React-хуки: localStorage, клик вне элемента, лента с догрузкой.

## Что внутри

- `index.ts` — публичный API — импортировать снаружи только отсюда
- `useClickOutside.ts` — вызывает `handler`, когда пользователь нажимает мышью или пальцем вне элемента `ref`; третий аргумент `enabled` выключает слушатель. Используется в Dropdown; тест — `useClickOutside.test.ts`
- `useInfiniteScroll.ts` — хук для реализации бесконечной ленты. Сначала отображается `batch` элементов. Когда пользователь прокручивает список до специального маркера в конце ленты, появляется спиннер. Через `delayMs` добавляется следующая порция из `batch` элементов. Четвёртый аргумент `resetKey` задаёт, когда выдача действительно новая: например, лайк может заменить ссылку `items`, но не должен сворачивать уже открытую ленту. Используется в разделах «Рекомендуем», в результатах фильтрации и поиска, а также в избранном.
- `useLocalStorage.ts` — useState, синхронизированный с localStorage

## Подключение useInfiniteScroll (P2-15)

`useInfiniteScroll(items, batch, delayMs, resetKey?)` возвращает `visibleItems`, `sentinelRef`, `isLoading`, `hasMore`. Маркер с `sentinelRef` размещаем после списка, `Loader` показываем по `isLoading`; размер и задержку берём из `CATALOG` в `@/shared/config`. По умолчанию `resetKey` равен ссылке `items`, поэтому новая ссылка сбрасывает ленту. Для изменяемых карточек передаём стабильный ключ фильтров или поиска: изменение данных карточки тогда не сворачивает уже догруженную выдачу. Смена `resetKey` или `batch` отменяет ожидающую догрузку. Каждая следующая порция требует прокрутки пользователя; автоматической цепочки загрузок нет.
После рендера проверяется DOM-маркер: прежний узел сохраняет IntersectionObserver и слушатели.
При замене или удалении маркера, начале догрузки и размонтировании старое наблюдение снимается.
Хук поддерживает появление маркера после первого рендера без смены публичного `sentinelRef`.
