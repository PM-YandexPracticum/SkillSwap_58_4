# src/shared/lib/hooks

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Универсальные React-хуки: задержка, localStorage, клик вне элемента, лента с догрузкой.

## Что внутри

- `index.ts` — публичный API — импортировать снаружи только отсюда
- `useClickOutside.ts` — вызывает `handler`, когда пользователь нажимает мышью или пальцем вне элемента `ref`; третий аргумент `enabled` выключает слушатель. Используется в Dropdown; тест — `useClickOutside.test.ts`
- `useDebounce.ts` — откладывает обновление значения (из шаблона; сейчас в плане не используется)
- `useInfiniteScroll.ts` — хук для реализации бесконечной ленты. Сначала отображается `batch` элементов. Когда пользователь прокручивает список до специального маркера в конце ленты, появляется спиннер. Через `delayMs` добавляется следующая порция из `batch` элементов. Догрузка происходит по мере прокрутки пользователя. Используется в разделах «Рекомендуем», в результатах фильтрации и поиска, а также в избранном. При изменении `items` (например, при применении новых фильтров) лента сбрасывается и начинается с первой порции.
- `useLocalStorage.ts` — useState, синхронизированный с localStorage
