# src/shared/lib/hooks

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

Универсальные React-хуки: задержка, localStorage, клик вне элемента, лента с догрузкой.

## Что внутри

- `index.ts` — публичный API — импортировать снаружи только отсюда
- `useClickOutside.ts` — Вызывает `handler`, когда пользователь кликает вне элемента `ref`. Нужен для закрытия выпадашек: «Все навыки», уведомления, меню пользователя
- `useDebounce.ts` — откладывает обновление значения (из шаблона; сейчас в плане не используется)
- `useInfiniteScroll.ts` — «Пагинация» в понимании наставника — бесконечная лента: сначала видно `batch` элементов, при прокрутке к концу на `delayMs` появляется спиннер и добавляется ещё `batch`. Догрузка — только по мере прокрутки пользователя. Используется в «Рекомендуем», в результатах фильтров/поиска и в избранном. При смене `items` (новые фильтры) лента начинается сначала
- `useLocalStorage.ts` — useState, синхронизированный с localStorage
