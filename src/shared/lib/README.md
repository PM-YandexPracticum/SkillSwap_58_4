# src/shared/lib

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../docs/architecture/fsd.md).

## Зачем эта папка

Утилиты общего назначения: форматирование, склонение, хуки, типизированные Redux-хуки.

## Что внутри

- [`hooks/`](hooks/README.md) — Универсальные React-хуки: localStorage, клик вне элемента, лента с догрузкой
- [`image/`](image/README.md) — Картинки: адрес для `<img src>` из значения в данных (`resolveImageUrl`: путь, data URL или заглушка) и превращение выбранного файла в data URL (`fileToDataUrl`)
- [`store/`](store/README.md) — Типизированные `useAppDispatch` / `useAppSelector`
- [`toast/`](toast/README.md) — контекст уведомлений и хук `useToast`
- [`validation/`](validation/README.md) — Общие правила валидации: готовые yup-поля (email, пароль, имя, дата рождения, текст, город) и проверка картинок
- `pluralize.ts` — Склоняет русское слово по числу
- `shuffle.ts` — перемешивает массив в случайном порядке (Фишер — Йетс), возвращает новый массив и не меняет вход; P4-03 вызывает его один раз при загрузке пользователей
- `shuffle.test.ts` — детерминированные перестановки, неизменность входа, пустой / единичный / readonly-массив, повторяющиеся элементы и ссылки на объекты

- `formatRecipientName.ts` — форма имени для текста предложения обмена: основные русские окончания, исключения (например, Павел → Павлу) и пол для мягкого знака. Латиница, составные и неподдерживаемые формы сохраняются; это не универсальный словарь имён. Общая функция для toast и вызывающей стороны панели уведомлений.
- `formatRecipientName.test.ts` — регулярные формы, исключения, пустое имя и безопасное поведение для неподдерживаемых форм.

- `createLookup.ts` — независимый отсортированный индекс с бинарным поиском по строковому ключу: подготовка O(n log n), поиск O(log n). Селекторы создают его только при смене коллекции, исходный порядок сохраняется.
- `createLookup.test.ts` — несортированный/пустой список, края, дубли, отсутствие записи и повторные поиски без извлечения ключей заново.
