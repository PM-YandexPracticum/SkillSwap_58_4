# src/shared/assets/icons

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

SVG-иконки из Figma. Импорт как React-компонент: `import HeartIcon from '@/shared/assets/icons/heart.svg?react'`.

## Требования к файлам

- **`viewBox="0 0 24 24"`** и **без `width`/`height`** — размер задаётся снаружи (CSS или пропсы `width`/`height` компонента).
- **`fill="currentColor"`** для заливных иконок, **`stroke="currentColor"`** для контурных — иконка принимает цвет родителя (`color` в CSS).
- **Никаких hex-цветов** внутри SVG — иначе иконка не перекрашивается и не работает в тёмной теме.
- Один файл = одна иконка, имя в `kebab-case`.

## Как добавить иконку

1. Экспортировать из Figma (только сам глиф, без подложек и фреймов).
2. Прогнать через [SVGOMG](https://jakearchibald.github.io/svgomg/), включив **Prettify**.
3. Убрать `width`/`height`, заменить жёсткие цвета на `currentColor`, у контурных путей выставить `fill="none"`.
4. Проверить визуально в браузере.
5. Сохранить в эту папку под осмысленным `kebab-case` именем.

| `bell.svg` | Уведомления в шапке |
| `business.svg` | Категория «Бизнес и карьера» |

| `close.svg` | Закрытие модалки, очистка поля поиска |
| `creative.svg` | Категория «Творчество и искусство» |
| `education.svg` | Категория «Образование и развитие» |
| `eye.svg` | Показать/скрыть пароль |
| `health.svg` | Категория «Здоровье и лайфстайл» |
| `heart.svg` | Лайк, «Избранное» |
| `home.svg` | Категория «Дом и уют» |
| `languages.svg` | Категория «Иностранные языки» |
| `moon.svg` | Переключение тёмной темы |
