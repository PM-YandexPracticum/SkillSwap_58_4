# src/shared/assets/icons

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

SVG-иконки из Figma. Импорт как React-компонент:

```ts
import LikeIcon from '@/shared/assets/icons/like.svg?react'
```

## Требования к файлам

- **`viewBox="0 0 24 24"`** и **без `width`/`height`** — размер задаётся снаружи (CSS или пропсы `width`/`height` компонента).
- **`fill="currentColor"`** для заливных иконок, **`stroke="currentColor"`** для контурных — иконка принимает цвет родителя (`color` в CSS).
- **Никаких hex-цветов** внутри SVG — иначе иконка не перекрашивается и не работает в тёмной теме.
- Один файл = одна иконка, имя в `kebab-case`.
- Имя файла совпадает с именем слоя в Figma. Где совпадение невозможно — причина в колонке «Примечание».
- Исключение по сетке: `user-circle.svg` — 56×56 (круг входит в саму иконку).

## Как добавить иконку

1. Экспортировать из Figma (только сам глиф, без подложек и фреймов).
2. Прогнать через [SVGOMG](https://jakearchibald.github.io/svgomg/), включив **Prettify**.
3. Убрать `width`/`height`, заменить жёсткие цвета на `currentColor` на корне `<svg>`, у контурных путей выставить `fill="none"`.
4. Проверить визуально в браузере.
5. Сохранить в эту папку под именем слоя Figma, добавить строку в таблицу ниже.

## Категории

Папка `categories/`. Имена файлов подобраны по смыслу категории, а не по слою Figma, — так понятнее в коде.
Пиктограмма и пастельная подложка-круг задаются CSS на компоненте, в файлах только currentColor (на странице «Все навыки» подложки нет — только глиф в тонкой обводке, это тоже CSS-вариант).
