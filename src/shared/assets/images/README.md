# src/shared/assets/images

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../docs/architecture/fsd.md).

## Зачем эта папка

SVG-иллюстрации экранов входа, регистрации и ошибок (P1-03).

## Что внутри

- `light-bulb.svg` — иллюстрация входа и первого шага регистрации.
- `user-info.svg` — иллюстрация второго шага регистрации.
- `school-board.svg` — иллюстрация третьего шага регистрации.
- `error-404.svg` — иллюстрация страницы 404.
- `error-500.svg` — иллюстрация страницы 500.

Импортируются из кода; фото пользователей, навыков и команды лежат в `public/images/`.
