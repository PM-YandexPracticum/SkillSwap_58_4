# src/shared/api/mock-db/seed

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../../docs/architecture/fsd.md).

## Зачем эта папка

Данные сайта: 45 пользователей с навыками, справочники категорий и городов, образцы обменов и уведомлений. Справочники и пользователей заполнила команда по образцу (задачи P1-05…P1-08). Тип каждой записи — в `entities/*/model/types.ts`.
По ТЗ наставника эти JSON должны лежать в `public/db` — тимлид перенесёт их после наполнения моков (задача P4-10).

## Что внутри

- [`skills/`](skills/README.md) — навыки, по одному на пользователя (45 шт.)
- [`users/`](users/README.md) — пользователи (45 шт.), среди них демо-аккаунт Марии
- `categories.json` — 6 категорий и 42 подкатегории
- `cities.json` — 17 городов
- `exchanges.json` — обмены (2 образца)
- `index.ts` — публичный API — импортировать снаружи только отсюда
- `notifications.json` — уведомления (2 образца)
