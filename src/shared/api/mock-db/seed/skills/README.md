# src/shared/api/mock-db/seed/skills

> **SkillSwap** — платформа обмена навыками (только фронтенд: React + TypeScript + Redux Toolkit).
> Архитектура — Feature-Sliced Design, подробности в [docs/architecture/fsd.md](../../../../../../docs/architecture/fsd.md).

## Зачем эта папка

Навыки — по одному на пользователя, 45 шт.; номер навыка совпадает с номером автора (`s18` — навык `u18`). Фото — `/images/skills/<id навыка>-<номер>.jpg`, 1–4 на навык, каждое до 200 КБ.

## Что внутри

- `index.ts` — публичный API — импортировать снаружи только отсюда
- `sample.json` — образцы `s01`–`s03`
- `part-1.json` — `s04`–`s17`: «Бизнес и карьера», «Творчество и искусство» (P1-06)
- `part-2.json` — `s18`–`s31`: «Иностранные языки», «Образование и развитие» (P1-07)
- `part-3.json` — `s32`–`s45`: «Здоровье и лайфстайл», «Дом и уют» (P1-08)
